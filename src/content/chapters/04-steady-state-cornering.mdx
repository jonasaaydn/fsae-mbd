## この章でできるようになること

- 定常円旋回の条件`β̇ = 0, ṙ = 0`が物理的に何を意味するか（車体固定の状態量は変化しないが、車両自体は一定の角速度`r`で回転し続けている）を説明できる。
- 第3章の状態方程式の定常解から、スタビリティファクタ`A_sf`の符号（`A_sf>0`アンダーステア・`A_sf=0`ニュートラル・`A_sf<0`オーバーステア）が、なぜそのままアンダー/オーバーステアの定義になるのかを式のレベルで説明できる。
- `A_sf`が**線形モデル**（`K_f`・`K_r`を定数とみなすモデル）だけに存在する性質であることを理解し、実車の非線形な挙動と混同しない。
- ヨーレートゲイン`r/δ`を速度`V`の関数として微分し、アンダーステア車が特性速度`V_ch = 1/√A_sf`でゲイン最大を取ること、オーバーステア車が臨界速度`V_cr = 1/√(−A_sf)`でゲインが発散することを、結果を覚えるのではなく自分で導出できる。
- アンダーステア勾配`K_us`とアッカーマンの関係式`δ = l/R + K_us·(a_y/g)`を、この章の定常ゲインの式から導出でき、Gillespie（1992）の重量ベースの定義`K_us = W_f/K_f − W_r/K_r`とスタビリティファクタ形`A_sf = K_us/(g·l)`が同じ主張の言い換えであることを代数で示せる。
- 車体すべり角`β`が低速では旋回の外側を、高速では内側を向くという符号反転（速度`V_β0`）を式から導出し、なぜこれが直感に反するかを説明できる。
- ニュートラルステアポイント（NSP）と静的余裕度`SM`を計算でき、横風など外部からの横力に対する応答を決めるのが重心ではなくNSPであることを説明できる。
- `K_us`が線形モデルの中だけの数ではなく、低横加速度域の定常円旋回試験（または一定舵角試験）で実車から直接測定できる量であることを知っている。
- **この章で求めた`K_us`・`A_sf`が横加速度に依存しない前提（`K_f`・`K_r`一定）の上に成り立っており、限界域（横加速度1g超）での実車の挙動——多くの場合、低`a_y`でのマイルドなアンダーステアが限界付近でオーバーステア方向へ遷移する——をこの線形モデルがまったく表現できないことを、誤読しない自信を持って説明できる。**

## なぜ必要か

第3章は状態方程式`ẋ = A·x + Bδ`を導出しましたが、その式は「舵を切った瞬間から車がどう応答していくか」という時間発展そのものを記述するもので、式を眺めただけでは「この車はアンダーステアなのかオーバーステアなのか」「舵角をいくつ増やせば旋回半径がどう変わるか」といった、レースエンジニアが日常的に使う語彙には直結しません。この章がすることは単純です。状態方程式に`β̇ = 0, ṙ = 0`——「これ以上変化していない」という定常状態の条件——を課し、その結果として第3章の終わりに提示された`A_sf`・`r/δ`・`a_y/δ`・`β/δ`という代数式を、物理的な意味を持つ量として読み解きます。

これらの式そのものはすでに第3章で導出済みです。この章の仕事は計算ではなく解釈です。`A_sf`の符号がなぜアンダー/オーバーステアと同じ意味になるのか、なぜアンダーステア車には「特性速度」というゲインが頭打ちになる特別な速度が存在するのか、なぜ車体すべり角の向きが速度によって反転するのか——これらはいずれも、式を出発点にしてはじめて答えられる問いです。感覚や経験則で「この車はアンダー気味だ」と言うことと、`A_sf`の符号を計算して言うことの違いは、後者が「なぜそうなるか」を式の中に持っている点にあります。

この章で手に入れる語彙（アンダーステア・オーバーステア・ニュートラルステア・スタビリティファクタ・アンダーステア勾配・特性速度・臨界速度・ニュートラルステアポイント・静的余裕度）は、本書のこの先ほぼすべての章で前提知識として使います。第5章（過渡応答）はこの章の定常解へ向かう「途中経過」を扱い、第13章（荷重移動とロール剛性配分）はこの章の`K_us`が一定という前提を外して実車のセットアップ判断に踏み込みます。第26章（実車データとの突き合わせ）は、この章の`K_us`を実際にどう測るかを扱います。

## 理論

### 定常円旋回条件：`β̇ = 0, ṙ = 0`が意味すること

第3章の状態方程式`ẋ = A·x + Bδ`において`β̇ = 0`かつ`ṙ = 0`とおくことを「定常」と呼びます。これは「車が止まっている」ことでも「何も変化していない」ことでもありません。**車体に固定した2つの状態量（車体すべり角`β`とヨーレート`r`）が、これ以上時間変化しない状態**という意味です。ヨーレート`r`自体はゼロではなく一定値のまま保たれます。つまり車両は、一定の角速度`r`で回転し続けながら、一定の車速`V`・一定の舵角`δ`・一定の車体すべり角`β`を保って走る——これはちょうど、定常円旋回（一定半径・一定速度でコーナーを回り続ける状態）そのものです。

この条件のもとで、重心の横加速度`a_y = V·(β̇ + r)`（第3章）は`a_y = V·r`に簡単化されます。さらに、車両が半径`R`の円を一定速度`V`で回っているとき、ヨーレートと旋回半径の間には運動学的な関係`r = V/R`が成り立ちます（車両の向きが、円周上を進む速さに応じて一定の角速度で変わり続けるだけです）。これを`a_y = V·r`に代入すると`a_y = V²/R`という、おなじみの向心加速度の式が出てきます。この`r = V/R`という関係は、この章のいたるところで使います。

`ẋ = 0`とおいた状態方程式`0 = A·x_ss + Bδ`を`x_ss`について解くと（`A`が正則である限り`x_ss = −A⁻¹Bδ`）、第3章の終わりに示した次の結果が得られます（導出そのものは第3章で完了しているので、ここでは結果を出発点にします）。

```text
A_sf  = -m·(l_f·K_f − l_r·K_r) / (l²·K_f·K_r)

r/δ   = (V/l) / (1 + A_sf·V²)
a_y/δ = (V²/l) / (1 + A_sf·V²)
β/δ   = [1 − m·l_f·V²/(l·l_r·K_r)]·(l_r/l) / (1 + A_sf·V²)
```

### スタビリティファクタ`A_sf`と3つのレジーム

`A_sf`の符号は、`r/δ`・`a_y/δ`の分母`1 + A_sf·V²`の振る舞いを支配します。

- **`A_sf > 0`（アンダーステア）。** 分母は速度とともに単調に増えるので、`r/δ`は速度が上がるにつれて頭打ちになっていきます。同じ舵角を当てても、速度が上がるほど得られるヨーレート（曲がる速さ）の伸びは鈍くなる——これが「アンダーステア」という言葉が指す現象です。
- **`A_sf = 0`（ニュートラルステア）。** 分母は常に1で、`r/δ = V/l`は速度に単純比例します。旋回半径`R = V/r = l/δ`は速度に依存せず舵角だけで決まる、もっとも素直な応答です。
- **`A_sf < 0`（オーバーステア）。** 分母`1 + A_sf·V²`はある速度でゼロを通過し、それより先では負になります。`r/δ`はその手前で発散し、その速度（臨界速度`V_cr`、次節）を超えると第3章で示した`det(A) > 0`の安定条件が破れます。

`A_sf`の符号を決めているのは`l_f·K_f − l_r·K_r`の符号です。これはブラシモデル（第2章）で導いた前後軸のコーナリングスティフネス`K_f`・`K_r`の**差**であり、タイヤの性能そのものと前後の重量配分の両方が効いてくる量です。

**ここで必ず確認しておくべきことがあります。`A_sf`はこの章の線形モデル（`K_f`・`K_r`を定数とみなすモデル）だけに存在する量です。** `K_f`・`K_r`は実際には荷重・スリップ角とともに変化する量（第2章の荷重感度、第8章のMagic Formula）であり、`A_sf`はそれらを「一定」と置いた近似の中でだけ、きれいな符号の3分類として現れます。この限界の具体的な影響は「限界と適用範囲」で扱います。

### ヨーレートゲインの速度依存性：特性速度と臨界速度を導出する

`A_sf > 0`のアンダーステア車では、`r/δ`は低速でほぼ`V/l`に比例して増え、高速では頭打ちになります。この間のどこかにゲインが最大になる速度があるはずです。それを導出します。

`r/δ`を`V`の関数として`f(V) = V / (1 + A_sf·V²)`と書き、商の微分則で微分すると

```text
f'(V) = [(1 + A_sf·V²) − V·(2·A_sf·V)] / (1 + A_sf·V²)²
      = (1 − A_sf·V²) / (1 + A_sf·V²)²
```

分母は`A_sf > 0`のとき常に正なので、`f'(V)`の符号は分子`1 − A_sf·V²`だけで決まります。`V`が小さいうちは`1 − A_sf·V² > 0`（増加）、`V`が大きくなると`1 − A_sf·V² < 0`（減少）に転じ、その境目

```text
1 − A_sf·V² = 0  ⟺  V = 1/√A_sf =: V_ch
```

で`f(V)`は増加から減少に転じます。増加から減少へ切り替わる点であり、かつこの範囲で唯一の臨界点でもあるので、これは`f(V)`の（大域的な）最大値です。**これが特性速度`V_ch`です。** 「ある速度でヨーレートゲインが最大になる」というのは仮定ではなく、`r/δ`という具体的な式の微分から出てくる結論です。

`A_sf < 0`（オーバーステア）の場合は、分母`1 + A_sf·V²`自体が`V = 1/√(−A_sf) =: V_cr`（臨界速度）でゼロを通過するため、`f(V)`は最大値を持たずに`V_cr`の手前で発散します。この`V_cr`は、第3章の安定性の節で示した`det(A) > 0 ⟺ 1 + A_sf·V² > 0`という安定条件の境界と完全に一致します——ゲインの発散と状態方程式の不安定化は、同じ`1 + A_sf·V² = 0`という1つの条件の2つの現れ方にすぎません。

### アンダーステア勾配`K_us`とアッカーマンの関係——2つの定義が同じであることを示す

`K_us`（アンダーステア勾配）は、レース工学の現場でもっとも頻繁に使われる指標です。定義は

```text
δ = l/R + K_us·(a_y/g)
```

——「幾何学的（アッカーマン）舵角`l/R`に、横加速度1gあたり`K_us`だけの追加の舵角が必要」という形の式です。これがこれまで導いた`A_sf`とどう結びつくかを導出します。

定常円旋回条件から`r = V/R`、`a_y = V·r = V²/R`（前節）が成り立つので、`r/δ`の式に`r = V/R`を代入すると

```text
(V/R) / δ = (V/l) / (1 + A_sf·V²)
```

両辺の`V`を消去して`δ`について解くと

```text
δ = l·(1 + A_sf·V²) / R = l/R + A_sf·l·V²/R
```

ここで`V²/R = a_y`（前節の関係）を使うと

```text
δ = l/R + (A_sf·l)·a_y
```

となります。これを`δ = l/R + K_us·(a_y/g)`と見比べると、`K_us·(a_y/g) = A_sf·l·a_y`より

```text
K_us = A_sf·g·l   ⟺   A_sf = K_us/(g·l)
```

が導けます。**つまり`K_us`は、この章で扱ってきた`A_sf`を「1gあたり何度の追加舵角が要るか」という、より実務的な単位に書き換えただけの量です。**

Gillespie（1992）は`K_us`を、タイヤ剛性ではなく**軸荷重**を使って`K_us = W_f/K_f − W_r/K_r`（`W_f = m·g·l_r/l`、`W_r = m·g·l_f/l`は前後軸の静止荷重）と定義しています。これを`A_sf = K_us/(g·l)`に代入すると

```text
A_sf = (W_f/K_f − W_r/K_r) / l
     = (m·g·l_r/(l·K_f) − m·g·l_f/(l·K_r)) / l
     = m·g·(l_r·K_r − l_f·K_f) / (l²·K_f·K_r·g)
     = -m·(l_f·K_f − l_r·K_r) / (l²·K_f·K_r)
```

となり、この章の冒頭に掲げた`A_sf`の式（第3章の結果）に**完全に一致**します。**タイヤ剛性の差から出発した`A_sf`の定義と、軸荷重の差から出発したGillespieの`K_us`の定義は、見た目こそ違いますが、同じ1つの主張の2通りの言い方にすぎません。** この一致は偶然ではありません。実装セクションのMATLABコードで、この一致を数値的にも確認します。

### 車体すべり角`β`の符号反転——低速で外向き、高速で内向き

`β/δ`の式をもう一度見ます。

```text
β/δ = [1 − m·l_f·V²/(l·l_r·K_r)]·(l_r/l) / (1 + A_sf·V²)
```

分母`1 + A_sf·V²`は`A_sf > 0`のアンダーステア車では常に正なので、`β/δ`の符号は角括弧の中身`1 − m·l_f·V²/(l·l_r·K_r)`だけで決まります。これがゼロになる速度が

```text
V_β0 = √(l·l_r·K_r / (m·l_f))
```

です。この式の意味を、両端の極限で確認します。

**`V → 0`の極限。** 角括弧は`1`に近づくので`β/δ → l_r/l > 0`です。速度がほぼゼロのとき、旋回に必要な横加速度`a_y = V²/R`もほぼゼロなので、タイヤはほとんど横力を必要とせず、車両はほぼ純粋な幾何学（アッカーマン的な運動学）で曲がります。このとき後輪はほとんどスリップ角なしに接地点の軌跡をなぞる一方、前輪だけが`δ`だけ切れているため、重心の速度ベクトルは前輪寄りに引っ張られます。**車体（中心線）は、重心の速度ベクトルより旋回の外側を向いている**ということです。

**`V > V_β0`の領域。** 角括弧が負に転じるため`β/δ < 0`になります。速度が上がるほど、旋回を維持するために必要な横加速度`a_y = V²/R`が大きくなり、それを生むための後軸スリップ角`α_r`（したがって後軸の横力）も大きくなります。後軸のスリップ角が大きくなるということは、後軸接地点の速度ベクトルが中心線から大きく傾くということであり、これが重心の速度ベクトルの向きを、車体中心線に対して**旋回の内側**へ引き込みます。

まとめると、**低速では車体（中心線）が進行方向（速度ベクトル）より外側を向き、高速では内側を向く**という反転が起こります。これは直感に反しやすい結果です。多くの学生は「車は常に進行方向をまっすぐ向いている」という感覚を持っていますが、実際には速度域によって車体の向きと進行方向の関係そのものが逆転します。ドリフト走行で車体が大きく外を向く現象（`β`が大きく正）は、まさにこの低速側の延長線上にある現象です。

### ニュートラルステアポイントと静的余裕度——横風応答を決めるのは重心ではない

ここまでは舵角`δ`という入力に対する応答を見てきました。最後に、舵角以外の外部からの横力（横風、片側だけの路面の凹凸など）に対する応答を特徴づける点を導入します。

車両に、重心から前方に距離`x`の位置で外部横力`F_ext`を加えたときの定常ヨーレート応答を考えると、`x`のある特定の値でヨーレート応答がちょうどゼロになります（横方向には並進するが、回転はしない）。この特別な点を**ニュートラルステアポイント（NSP）**と呼び、重心からの前方距離は

```text
a_e = (l_f·K_f − l_r·K_r) / (K_f + K_r)
```

で与えられます（前軸から測った距離では`l·K_r/(K_f+K_r)`）。この式の分子`l_f·K_f − l_r·K_r`は、`A_sf`の分子`-m·(l_f·K_f − l_r·K_r)`と符号が逆なだけの同じ量なので、次の同値関係が成り立ちます。

```text
A_sf > 0（アンダーステア） ⟺ a_e < 0（NSPが重心より後方）
```

静的余裕度`SM`は、この位置関係を無次元の比率として表したもので、Millikenの符号規約（後方を正）では

```text
SM = (l_r·K_r − l_f·K_f) / (l·(K_f + K_r)) = -a_e/l
```

です。`SM`が大きいほど（NSPが重心よりしっかり後方にあるほど）、車はよりアンダーステア側に安定しています。航空機の静安定余裕（重心と空力中心の関係）と同じ発想の量であることに注意してください。

**ここで実務上重要な点を一つ指摘します。** 横風のような外部からの横力に対する車両の応答（どちら向きにヨーが立つか、どれだけ立つか）を決めるのは、**重心の位置ではなく、NSPと外力の作用点（横風であれば、車体側面に対する風圧中心）との相対位置**です。「重心が前寄りだから横風に弱い」という言い方は不正確で、正しくは「NSPと風圧中心の位置関係」で決まります。空力パーツの追加・変更で車両側面の風圧中心が動けば、重心をまったく動かさなくても横風応答は変わりえます。

## 実装

以下のMATLABコードは、次の5つを実装します。base MATLABの機能（`sqrt`・`max`・`assert`・`fprintf`・`plot`・`xline`・`yline`）のみを使用しており、追加のToolboxは不要です。パラメータは**第3章と同じ仮の値**を使い、両章が同じ車両を指していることを明示します。

1. スタビリティファクタ`A_sf`の計算（第3章の結果の再掲）
2. アンダーステア勾配`K_us`を、`A_sf`由来の式とGillespie（1992）の重量ベースの式の**2通り**で計算し、一致することを`assert`で確認する単体テスト（理論の節で示した代数の検算）
3. 特性速度`V_ch`（または臨界速度`V_cr`）と、車体すべり角の符号反転速度`V_β0`の計算
4. ニュートラルステアポイント`a_e`と静的余裕度`SM`の計算
5. 速度を掃引したヨーレートゲイン`r/δ`・車体すべり角ゲイン`β/δ`の計算とプロット。`r/δ`の数値上の最大値の位置が`V_ch`と一致すること、`β/δ`の符号が`V_β0`の前後で反転することを、それぞれ`assert`で確認する単体テスト

```matlab
% 定常円旋回：スタビリティファクタ・アンダーステア勾配・特性速度・NSPの計算
% 第3章の状態方程式 xdot = A*x + B*delta に、定常円旋回条件 beta_dot=0, r_dot=0 を
% 課した結果（第3章で導出済み）を、この章では計算し物理的に解釈する。
% ISO 8855: x 前方 / y 左 / z 上向き（第1章の座標系に準拠）
%
% base MATLAB のみを使用（Control System Toolbox 不使用）。

clear; clc;

%% 1. 車両諸元（第3章と同じ仮の値。実測ではない）
p.m   = 280;      % kg     車両質量+ドライバ（仮定）
p.Iz  = 115;      % kg*m^2 ヨー慣性モーメント（仮定）
p.lf  = 0.79;     % m      重心〜前軸距離（仮定）
p.lr  = 0.76;     % m      重心〜後軸距離（仮定）
p.l   = p.lf + p.lr;   % m  ホイールベース
p.Kf  = 105000;   % N/rad  前軸コーナリングスティフネス（仮定）
p.Kr  = 130000;   % N/rad  後軸コーナリングスティフネス（仮定）
g_acc = 9.81;     % m/s^2  重力加速度

fprintf('--- 車両諸元（第3章と同じ仮の値、実測ではない） ---\n');
fprintf('m=%.1f kg, Iz=%.1f kg*m^2, lf=%.2f m, lr=%.2f m, l=%.2f m\n', p.m, p.Iz, p.lf, p.lr, p.l);
fprintf('Kf=%.0f N/rad, Kr=%.0f N/rad\n\n', p.Kf, p.Kr);

%% 2. スタビリティファクタ A_sf（第3章の結果の再掲）
Asf = -p.m*(p.lf*p.Kf - p.lr*p.Kr) / (p.l^2*p.Kf*p.Kr);
fprintf('--- スタビリティファクタ ---\n');
fprintf('A_sf = %.6e s^2/m^2\n', Asf);
if Asf > 0
    fprintf('A_sf > 0 -> アンダーステア\n');
elseif Asf < 0
    fprintf('A_sf < 0 -> オーバーステア\n');
else
    fprintf('A_sf = 0 -> ニュートラルステア\n');
end

%% 3. 単体テスト1: アンダーステア勾配 K_us を2通りで求め、一致を確認する
% 方法1: delta = l/R + K_us*(ay/g) の定義と A_sf = K_us/(g*l) の関係（理論の節で導出）
Kus_from_Asf = Asf * g_acc * p.l;

% 方法2: Gillespie(1992)の重量ベースの定義 K_us = Wf/Kf - Wr/Kr
Wf = p.m*g_acc*p.lr/p.l;   % 前軸静止荷重
Wr = p.m*g_acc*p.lf/p.l;   % 後軸静止荷重
Kus_gillespie = Wf/p.Kf - Wr/p.Kr;

fprintf('\n--- 単体テスト1: K_us の自己チェック（A_sf由来 vs Gillespieの重量ベース） ---\n');
fprintf('Wf=%.2f N, Wr=%.2f N\n', Wf, Wr);
fprintf('K_us (A_sf*g*l)              = %.8e rad (%.4f deg/g)\n', Kus_from_Asf, rad2deg(Kus_from_Asf));
fprintf('K_us (Gillespie: Wf/Kf-Wr/Kr) = %.8e rad (%.4f deg/g)\n', Kus_gillespie, rad2deg(Kus_gillespie));
assert(abs(Kus_from_Asf - Kus_gillespie) < 1e-9, ...
    'K_usの2通りの計算が一致しません（理論の節の代数を確認）');
fprintf('-> 一致。タイヤ剛性差から出た定義と軸荷重差から出た定義が同じ量であることを確認。\n\n');

%% 4. 特性速度 V_ch（または臨界速度 V_cr）と beta 符号反転速度 V_beta0
if Asf > 0
    Vch = 1/sqrt(Asf);
    fprintf('特性速度 V_ch = 1/sqrt(A_sf) = %.2f m/s (%.1f km/h)\n', Vch, Vch*3.6);
elseif Asf < 0
    Vcr = 1/sqrt(-Asf);
    fprintf('臨界速度 V_cr = 1/sqrt(-A_sf) = %.2f m/s (%.1f km/h)\n', Vcr, Vcr*3.6);
end
Vbeta0 = sqrt(p.l*p.lr*p.Kr/(p.m*p.lf));
fprintf('車体すべり角の符号反転速度 V_beta0 = %.2f m/s (%.1f km/h)\n\n', Vbeta0, Vbeta0*3.6);

%% 5. ニュートラルステアポイントと静的余裕度
ae = (p.lf*p.Kf - p.lr*p.Kr) / (p.Kf + p.Kr);              % 重心から前方[m]（負なら後方）
SM = (p.lr*p.Kr - p.lf*p.Kf) / (p.l*(p.Kf + p.Kr));         % Milliken規約（後方が正）
fprintf('--- ニュートラルステアポイントと静的余裕度 ---\n');
fprintf('a_e = %.4f m（重心から前方。負の値はNSPが重心の後方にあることを示す）\n', ae);
fprintf('SM  = %.4f (%.2f%%)（Milliken規約：後方が正）\n', SM, SM*100);
assert(abs(SM - (-ae/p.l)) < 1e-12, 'SMとa_eの関係式が一致しません');
fprintf('-> A_sf>0（アンダーステア）とNSPが重心後方にあることの整合を確認。\n\n');

%% 6. 単体テスト2: 速度を掃引し、r/delta の数値上の最大値が V_ch と一致するか確認
V_sweep = 5:0.1:150;    % m/s（V_chが実用速度域よりかなり高いことを示すため広めに掃引）
r_gain    = (V_sweep/p.l) ./ (1 + Asf*V_sweep.^2);
ay_gain   = (V_sweep.^2/p.l) ./ (1 + Asf*V_sweep.^2);
beta_gain = (1 - p.m*p.lf*V_sweep.^2/(p.l*p.lr*p.Kr)) .* (p.lr/p.l) ./ (1 + Asf*V_sweep.^2);

[r_gain_max, idx_max] = max(r_gain);
V_at_peak = V_sweep(idx_max);
fprintf('--- 単体テスト2: r/delta の数値上の最大値の位置 vs V_ch ---\n');
fprintf('V_ch(解析式) = %.2f m/s, 掃引での最大値の位置 = %.2f m/s（刻み %.1f m/s, 最大値 %.4f）\n', ...
    Vch, V_at_peak, V_sweep(2)-V_sweep(1), r_gain_max);
assert(abs(V_at_peak - Vch) <= (V_sweep(2)-V_sweep(1)) + 1e-6, ...
    '数値的な最大値の位置がV_chと一致しません');
fprintf('-> 一致（掃引刻みの精度内）。理論の節で導いた極大条件 1-A_sf*V^2=0 を数値的に確認。\n\n');

figure;
subplot(2,1,1);
plot(V_sweep, r_gain, '-'); hold on;
xline(Vch, '--');
xlabel('V [m/s]'); ylabel('r/\delta [1/(s\cdot rad)]');
title('ヨーレートゲイン r/\delta の速度依存性（V_{ch} を破線で表示）');
grid on;

subplot(2,1,2);
plot(V_sweep, beta_gain, '-'); hold on;
yline(0, ':');
xline(Vbeta0, '--');
xlabel('V [m/s]'); ylabel('\beta/\delta [-]');
title('車体すべり角ゲイン \beta/\delta の速度依存性（V_{\beta0} を破線で表示）');
grid on;

%% 7. 単体テスト3: beta/delta の符号が V_beta0 の前後で反転するか
V_below = 0.9*Vbeta0;
V_above = 1.1*Vbeta0;
beta_below = (1 - p.m*p.lf*V_below^2/(p.l*p.lr*p.Kr)) * (p.lr/p.l) / (1 + Asf*V_below^2);
beta_above = (1 - p.m*p.lf*V_above^2/(p.l*p.lr*p.Kr)) * (p.lr/p.l) / (1 + Asf*V_above^2);
fprintf('--- 単体テスト3: beta/delta の符号反転（V_beta0=%.2f m/s の前後） ---\n', Vbeta0);
fprintf('V=%.2f m/s (<V_beta0): beta/delta = %+.4f\n', V_below, beta_below);
fprintf('V=%.2f m/s (>V_beta0): beta/delta = %+.4f\n', V_above, beta_above);
assert(beta_below > 0 && beta_above < 0, 'V_beta0の前後でbeta/deltaの符号が反転していません');
fprintf('-> 低速で正（機首が旋回の外側を向く）、高速で負（機首が内側を向く）への反転を確認。\n');
```

`p.m`・`p.Iz`・`p.lf`・`p.lr`・`p.Kf`・`p.Kr`は第3章と同じ仮の値であり、実測値ではありません。自分のチームの値で確認する場合は、第24〜25章の手順で同定した値に置き換えてください。

## 限界と適用範囲

この章の結果——`A_sf`・`K_us`・`V_ch`・`V_β0`・NSP——は、すべて第3章の8つの前提の上に成り立っています。中でも実務上もっとも見落とされやすく、もっとも高くつく前提を、この章の結論として改めて明記します。

**1. `K_us`は`a_y → 0`の極限値であり、横加速度に依存しない。** この章の`A_sf`・`K_us`は、`K_f`・`K_r`を定数として計算した結果です。実際のタイヤは荷重・スリップ角とともに`C_α`が変化する（第2章の劣線形性）うえ、荷重移動によって左右輪の`F_z`も変わるため、実車の`K_us`は横加速度`a_y`とともに変化します。多くのレース車両で典型的に見られる傾向は、**低い`a_y`ではマイルドなアンダーステア、限界に近い高い`a_y`ではオーバーステア方向へ移る**という遷移です。この遷移こそが、セットアップエンジニアが「エントリーはアンダー、エグジットでリアが出る」といった言い方で日常的に語っている現象そのものです。**しかしこの章の線形モデルは、`K_f`・`K_r`を定数と置いた瞬間に、この遷移を表現する自由度そのものを失っています。** `K_us`が`a_y`の関数として変化するという発想が、この章のどの式の中にも存在しません。

**2. だからこの章で計算した`K_us`・`A_sf`を、自分の車の「限界での挙動」だと読んではいけません。** 第3章で確認した通り、この線形モデルが妥当なのは横加速度がおよそ0.3〜0.4g程度までであり、**学生フォーミュラは常時1g超で走ります。** つまりこの章で計算した`A_sf`・`K_us`の符号や大きさは、走行域のごく一部（コーナー進入のごく初期など）でしか実車の挙動を代表せず、**限界旋回でのバランス（リアが出るかフロントが逃げるか）を予測する数値としては使えません。** この誤読——「計算したら`A_sf>0`だったから、この車は限界でもアンダーステアだ」——は、この章がもたらしうる最大の実務上の害です。限界域での`K_us`の`a_y`依存性（ハンドリングダイアグラム）は、荷重移動と非線形タイヤの両方が入る第13章・第II部で扱います。

**3. `V_cr`を「その速度で必ずスピンする速度」と読まない（第3章からの継続）。** `A_sf < 0`のオーバーステア車における`V_cr`は、**開ループ**（舵角固定）での発散速度です。ドライバが閉ループで（ハンドルを戻しながら）安定化していれば`V_cr`を超えても走れますし、逆に`V_cr`以下でも舵角が大きすぎてタイヤが飽和すればスピンします。線形安定性は限界挙動の必要条件でも十分条件でもありません。

**4. NSP・静的余裕度も同じ`K_f`・`K_r`一定の前提の上にある。** 荷重移動が起きればNSPの位置も動くため、この章で計算した`a_e`・`SM`も、あくまで低`a_y`での近似値です。

**それでもこの章の`K_us`には、他の限界を大きく上回る価値が1つあります。`K_us`は、線形モデルの中だけの数ではなく、実車から直接測定できる量です。** 第3章の`ω_n`・`ζ`のような周波数応答の指標と違い、`K_us`は低い横加速度域で一定半径旋回試験（半径`R`を固定し、速度`V`を掃引しながら舵角`δ`を記録する）または一定舵角試験（舵角`δ`を固定し速度を上げながら`a_y`を記録する）を行い、`δ − l/R`を`a_y/g`に対してプロットしてその傾きを読むだけで得られます。**この章の理論が正しいかどうかは、感覚ではなく、この試験1回で白黒つけられます。** 具体的な試験手順・データ処理・低`a_y`域だけを使うべき理由は第26章（実車データとの突き合わせ）で扱います。

## 学生チームでの現実解

1. **まず第3章のMATLABコードの`p`を自チームの値に置き換え、この章のコードで`A_sf`・`K_us`・`V_ch`（または`V_cr`）・`V_β0`・NSP・`SM`を計算する。** 通常のFSAE車では`A_sf`が小さく、`V_ch`が実用速度域よりずっと高い値になりやすいはずです。もし計算した`V_ch`や`V_cr`が実用速度域に近ければ、まず`K_f`と`K_r`の前後取り違え、単位（rad/deg）の取り違えを疑ってください。
2. **計算した`K_us`を、「コーナー進入初期での挙動の目安」としてだけ扱う。** 「限界でのバランス」の議論には使わないでください。限界でのバランスは第13章以降の4輪モデル・非線形タイヤモデルで扱う対象です。
3. **低`a_y`域の一定半径旋回試験（または一定舵角試験）で、実車の`K_us`を測る。** スキッドパッドなど一定半径のコースを使い、速度を段階的に上げながら舵角（またはステアリングホイール角をラック比で除した実舵角）を記録し、`δ − l/R`を`a_y/g`に対してプロットします。低`a_y`側の傾きが、この章で計算した`K_us`の実測値です。試験の詳しい手順・注意点（タイヤ温度の影響、路面の温度履歴による`μ`のドリフトなど）は第26章にまとめます。
4. **`a_y`を上げていったときに`K_us`がどう変化するかも同時に記録する。** 傾きが横加速度とともに一定でないこと（多くの場合、`a_y`が上がるほどオーバーステア方向に変化すること）を自分のデータで確認できれば、この章の「限界と適用範囲」で述べた限界を、自チームの車で体感的に理解できます。
5. **横風・空力パーツの変更に伴う挙動変化を議論するときは、重心ではなくNSPと風圧中心の位置関係で考える。** ウイング角度やアンダートレイの変更で車体側面の風圧中心が動けば、重心を一切動かさなくても横風応答（高速直線でのふらつき）は変わりえます。
6. **今すぐ試せる最初のステップ：** 本章のMATLABコードをそのまま実行し（環境が無ければ手計算でも構いません）、`K_us`の2つの計算方法（`A_sf`由来とGillespieの重量ベース）が本当に一致するかを自分の手で確かめてください。そのうえで`K_f`と`K_r`を入れ替えたときに`A_sf`の符号とNSPの前後関係がどちらも同時に反転すること、`l_f`を大きくした（重心を後ろに動かした）ときに`SM`がどちらに動くかを、手を動かして確認してください。次章（過渡応答）に進む前に、この章の`A_sf`・`K_us`・NSPが同じ1つの物理を指す3つの表現である、という感覚を持っておくことが重要です。
