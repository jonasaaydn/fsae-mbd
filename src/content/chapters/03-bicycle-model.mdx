## この章でできるようになること

- 線形2輪モデルが置く前提（定速・微小角・線形タイヤ・左右一体化・荷重移動なしなど）を列挙し、それぞれが何を無視しているかを言える。
- タイヤ単体のスリップ角（第2章）を、車体すべり角`β`・ヨーレート`r`・車速`V`・舵角`δ`という車両レベルの量から`α_f`・`α_r`として導出できる。
- 横方向の力のつり合いとヨーまわりのモーメントのつり合いから、`β`と`r`を状態とする状態方程式`ẋ = A·x + B·δ`を自分の手で導出できる。
- 状態行列`A`の固有値から安定性を判定でき、2×2行列では`tr(A)<0`かつ`det(A)>0`に帰着することを知っている。
- スタビリティファクタ`A_sf`・定常ヨーレートゲイン`r/δ`・横加速度ゲイン`a_y/δ`・特性速度`V_ch`・臨界速度`V_cr`を、状態方程式の定常解として導出できる（物理的な意味づけは第4章で行う）。
- 過渡応答が零点を1つ持つ2次系になることと、その零点・固有振動数・減衰比が状態行列の跡・行列式からどう決まるかを式のレベルで知っている（時間応答の詳しい解析は第5章）。
- この線形モデルが実際に成立するのは横加速度およそ0.3〜0.4gまでであり、常時1g超で走るFSAEの走行域のほぼ全域で前提が破綻していることを説明でき、それでもこのモデルが役に立つ場面（用語定義・設計目標・状態推定器やLQR/MPCの内部モデル）を言える。
- base MATLABだけで状態方程式を組み、固有値・安定性・ゲインを計算し、符号規約（正の舵角がどちら向きのヨーレートを生むか）を単体テストで確認できる。

## なぜ必要か

前章では、前軸・後軸それぞれのタイヤが生む横力を`F_y = -K·α`という1本の直線で表せること、そしてその傾き`K`（軸あたり、`K = 2·C_α`）がブラシモデルの接地長・トレッド剛性・摩擦から導出できる数であることを固定しました。しかしタイヤの式だけでは車は動きません。タイヤが生む力と、車両の質量`m`・ヨー慣性`I_z`・重心位置（`l_f`・`l_r`）が組み合わさって初めて、舵を切ったときに車がどう応答するかが決まります。この章はその組み合わせ方——運動方程式——を扱います。

具体的には、前後輪を1本ずつの仮想的な車輪にまとめた**線形2輪モデル**（線形単軌道モデル）を組み立て、状態`x = [β, r]ᵀ`（車体すべり角とヨーレート）・入力`δ`（前輪舵角）の**状態方程式**`ẋ = A·x + B·δ`にします。この形にする理由は3つあります。第一に、状態方程式にすれば`eig`一発で安定性が判定できます。第二に、定常解（`ẋ=0`）を解けば、次章で使うスタビリティファクタやヨーレートゲインが代数的に出てきます。第三に、状態方程式はラプラス変換すれば伝達関数になり、次々章の過渡応答（ステップ操舵にどう遅れて応答するか）にそのままつながります。つまりこの章は、第4章（定常円旋回）と第5章（過渡応答）の両方が使う共通の土台を作る章です。

ただし先に言っておかなければならないことがあります。この章で導出するモデルが成立するのは、タイヤが線形域にとどまる横加速度およそ0.3〜0.4g程度までです（前章のブラシモデルが示した`Fy = μFz`という飽和が、まさにこの範囲を超えたところで効いてきます）。学生フォーミュラは常時1g超で走ります。つまりこの章のモデルは、**FSAEが実際に走る領域のほぼ全域で、前提そのものが崩れています。** それでもこの章を丁寧に組み立てる理由は、「限界性能の予測」以外にこのモデルには明確な使い道があるからです——ヨーレートゲインや応答時間という設計目標を数値で決めること、そして状態推定器（第35章）・LQR（第37章）・MPC（第39章）が内部で使う「プラントモデル」としての役割です。**この章のモデルが自分の車の限界挙動を言い当てると思ってしまったら、それはこの章の伝え方が悪いということです。** どこで前提が崩れるかは、理論を導出した直後の「限界と適用範囲」で具体的に扱います。

## 理論

### 仮定：この章が置く8つの前提

以下の前提を置きます。第4〜6章で1つずつ、どこまで有効かを検証していきます。

1. **前進速度`V`は一定の定数とする。** 縦方向の運動（加減速）を状態から外します。制動しながらの旋回やコーナー立ち上がりの加速は表現できません。
2. **左右輪を1本の仮想的な車輪にまとめる。** 前軸・後軸それぞれで左右の荷重移動とタイヤの荷重感度（第2章の劣線形性）を無視します。ARB・ばね・ロール剛性配分の効果はこのモデルにはいっさい現れません（第13章）。
3. **タイヤ横力はスリップ角に比例する：`F_y = -K·α`。** `K`は軸あたりのコーナリングスティフネス（第2章）で、1輪あたりの`C_α`を使う文献では`K = 2·C_α`です（本書はこの章以降、常に軸あたりの`K_f`・`K_r`を使います）。`|α|`がおよそ2〜3°を超える領域や、摩擦飽和`μF_z`に近い領域では成立しません（第8章のMagic Formula）。
4. **スリップ角`α_f`・`α_r`・舵角`δ`・車体すべり角`β`はすべて微小とする。** `sin θ ≈ θ`、`cos θ ≈ 1`という近似を使います。
5. **ロール・ピッチ・上下動なし。** 車体は水平面内の並進2自由度＋ヨー1自由度としてのみ動きます。
6. **空力はゼロまたは速度に依存しない定数として無視する。** 空力の効果（ダウンフォースの前後配分など）は第15〜16章。
7. **前後力`F_x`はゼロ（純横滑り）。** 加減速中の旋回（複合スリップ）は第10章。
8. **単軌道（2輪）モデルは4輪車を表現するモデルである。** 「重心が路面高さにある」「質点である」といった仮定は、このモデル自身は要求していません（Guiggiani, 2026）。文献で"single track vehicle"という言葉が出てきたとき、それが本物の二輪車（オートバイ）を指している場合があることにも注意してください——Sharp（1976）の同名論文はオートバイの動力学を扱ったもので、本章のモデルの典拠ではありません。この用語の罠は「限界と適用範囲」で改めて扱います。

### スリップ角を車両レベルの量で表す

第2章では、タイヤ単体の接地点における速度成分`v_x`・`v_y`から`α`を直接定義しました。ここではその`v_x`・`v_y`を、車両レベルの量——車体すべり角`β`、ヨーレート`r`、車速`V`、舵角`δ`——から組み立て直します。

重心の速度ベクトルは、車両中心線から角度`β`だけ傾いています（`tan β ≈ v_y/V`、`v_y`は重心の横速度）。前軸・後軸の接地点は、重心が角速度`r`で回転しているぶんだけ、それぞれ異なる速度方向を持ちます。前軸は重心より`l_f`前方にあるので、その接地点の速度は中心線から`β + l_f·r/V`だけ傾き、後軸は重心より`l_r`後方にあるので`β − l_r·r/V`だけ傾きます（微小角近似）。

前輪はさらに舵角`δ`だけ切れているので、前輪のホイール面（タイヤの向き）は中心線から`δ`だけ傾いています。後輪は舵角を持たないので、ホイール面は中心線と一致します。第2章の定義（スリップ角＝ホイール面から接地点の速度ベクトルまでの角度）をそのまま適用すると、

```text
α_f = β + l_f·r/V − δ
α_r = β − l_r·r/V
```

となります。

### 運動方程式：横方向の力のつり合いとヨーまわりのモーメントのつり合い

前後軸のタイヤ横力は、第2章の線形則`F_y = -K·α`（軸あたり）から

```text
Fyf = -K_f·α_f = -K_f·(β + l_f·r/V − δ)
Fyr = -K_r·α_r = -K_r·(β − l_r·r/V)
```

です。

**横方向の力のつり合い。** 重心の横加速度は`a_y = v̇_y + V·r`（`V`一定の仮定のもとで）、`v_y ≈ V·β`なので`v̇_y ≈ V·β̇`、よって`a_y = V·(β̇ + r)`。ニュートンの第2法則`m·a_y = Fyf + Fyr`に代入すると

```text
m·V·(β̇ + r) = Fyf + Fyr
            = -K_f·(β + l_f·r/V − δ) − K_r·(β − l_r·r/V)
            = -(K_f+K_r)·β − (l_f·K_f − l_r·K_r)·r/V + K_f·δ
```

**ヨーまわりのモーメントのつり合い。** 前軸の力は重心から`l_f`前方、後軸の力は`l_r`後方に作用するので

```text
I_z·ṙ = l_f·Fyf − l_r·Fyr
      = -l_f·K_f·(β + l_f·r/V − δ) + l_r·K_r·(β − l_r·r/V)
      = -(l_f·K_f − l_r·K_r)·β − (l_f²·K_f + l_r²·K_r)·r/V + l_f·K_f·δ
```

2つの式をそれぞれ`β̇`・`ṙ`について解くと、

```text
β̇ = -(K_f+K_r)/(m·V)·β − [1 + (l_f·K_f − l_r·K_r)/(m·V²)]·r + K_f/(m·V)·δ

ṙ = -(l_f·K_f − l_r·K_r)/I_z·β − (l_f²·K_f + l_r²·K_r)/(I_z·V)·r + (l_f·K_f)/I_z·δ
```

を得ます。

### 状態方程式の標準形

状態`x = [β, r]ᵀ`、入力`u = δ`とすると、上の2式はそのまま`ẋ = A·x + B·u`の形にまとまります。

```text
      ⎡ -(K_f+K_r)/(mV)          -1-(l_f K_f - l_r K_r)/(mV²)  ⎤
A  =  ⎢                                                        ⎥
      ⎣ -(l_f K_f - l_r K_r)/I_z  -(l_f² K_f + l_r² K_r)/(I_z V) ⎦

      ⎡ K_f/(mV)    ⎤
B  =  ⎢             ⎥
      ⎣ l_f K_f/I_z ⎦
```

`A`は車速`V`に依存することに注意してください。線形時不変（LTI）系として扱えるのは「ある一定の`V`のもとで」であり、`V`が変化する状況（加減速中）では`A`もその都度変わります（ゲインスケジューリングの発想そのもので、第39章のMPCが使う考え方につながります）。

観測量として、ヨーレート`r`（状態そのもの）と横加速度`a_y = (Fyf+Fyr)/m`を出力`y = [r, a_y]ᵀ`にとると、出力方程式`y = C·x + D·u`は

```text
      ⎡ 0              1                         ⎤
C  =  ⎢                                           ⎥
      ⎣ -(K_f+K_r)/m   -(l_f K_f - l_r K_r)/(mV)  ⎦

      ⎡ 0     ⎤
D  =  ⎢       ⎥
      ⎣ K_f/m ⎦
```

となります（`a_y`の式は横方向の力のつり合いの式をそのまま`m`で割ったものです）。

**記号の衝突について、ここで1度だけ注意します。** 本節の状態行列`A`（2×2）と、次節で導入する「スタビリティファクタ」は、文献（安部, 2012）でしばしば同じ文字`A`が使われます。本書はこの衝突を避けるため、スタビリティファクタを`A_sf`と表記します。

### 安定性：固有値と、トレース・行列式への帰着

状態方程式`ẋ = A·x + B·δ`の安定性は、`A`の固有値の実部がすべて負であることと同値です。2×2行列の固有値`λ_{1,2}`は特性方程式`λ² − tr(A)·λ + det(A) = 0`の解なので、次が成り立ちます。

- `tr(A) = -(K_f+K_r)/(mV) - (l_f²K_f+l_r²K_r)/(I_z V)`は、`m, I_z, V, K_f, K_r`がすべて正である限り常に負です（エネルギーを消費する側にしか効かない、という物理的に自然な結果です）。
- したがって安定性は`det(A) > 0`だけで決まります。展開すると

```text
det(A) = l²·K_f·K_r·(1 + A_sf·V²) / (m·I_z·V²)
```

（`l = l_f+l_r`、`A_sf`は次節のスタビリティファクタ）となり、`det(A) > 0 ⟺ 1 + A_sf·V² > 0`に帰着します。`A_sf ≥ 0`（アンダーステア〜ニュートラル）なら任意の`V>0`で常に安定、`A_sf < 0`（オーバーステア）なら`V < V_cr = 1/√(-A_sf)`でのみ安定という、次節の結果を先取りする形になります。

### 定常円旋回の結果（第4章が解釈する）

`ẋ = 0`（`β̇ = ṙ = 0`）とおいて`A·x_ss = -B·δ`を解くと、定常状態での`β`・`r`が舵角`δ`の線形関数として求まります。結果だけを示します。この結果が意味すること——なぜ`A_sf`の符号がアンダー/オーバーステアを決めるのか、なぜ特性速度でゲインが最大になるのか——は第4章で扱います。

**スタビリティファクタ**

```text
A_sf = -m·(l_f·K_f − l_r·K_r) / (l²·K_f·K_r)
```

`A_sf > 0`でアンダーステア、`A_sf = 0`でニュートラルステア、`A_sf < 0`でオーバーステアです。

**定常ゲイン**

```text
r/δ   = (V/l) / (1 + A_sf·V²)                                       [ヨーレートゲイン]
a_y/δ = (V²/l) / (1 + A_sf·V²)                                      [横加速度ゲイン]
β/δ   = [1 − m·l_f·V²/(l·l_r·K_r)]·(l_r/l) / (1 + A_sf·V²)          [車体すべり角ゲイン]
```

**特性速度と臨界速度**

`A_sf > 0`のとき、ヨーレートゲインが最大になる速度（特性速度）`V_ch = 1/√A_sf`が存在します。`A_sf < 0`のときはゲインが発散する速度（臨界速度）`V_cr = 1/√(-A_sf)`が存在し、その手前でしか安定しません（前節の`det(A)>0`条件と一致）。

**車体すべり角の符号反転速度**

```text
V_β0 = √(l·l_r·K_r / (m·l_f))
```

**アンダーステア勾配との関係**

`δ = l/R + K_us·(a_y/g)`と定義すると`A_sf = K_us/(g·l)`です。Gillespie（1992）の`K_us = W_f/K_f − W_r/K_r`（`W_f = m·g·l_r/l`、`W_r = m·g·l_f/l`は前後軸荷重）を代入すると、上の`A_sf`の式に一致します。

**ニュートラルステアポイントと静的余裕度**

重心から前方`a_e = (l_f·K_f − l_r·K_r)/(K_f+K_r)`の位置（前軸からの距離では`l·K_r/(K_f+K_r)`）に、ニュートラルステアポイント（NSP、そこに横力を加えてもヨーが発生しない点）があります。アンダーステア（`A_sf>0`）はNSPが重心より後方にあることと同値で、静的余裕度`SM = (l_r·K_r − l_f·K_f)/(l·(K_f+K_r))`（Millikenの符号規約：後方が正）で定量化します。

### 過渡応答の構造（第5章への前振り）

状態方程式をラプラス変換すると、舵角からヨーレートへの伝達関数が得られます。詳しい時間応答の解析（オーバーシュートの有無、応答時間の設計）は第5章に譲り、ここでは構造だけを示します。

```text
r(s)/δ(s) = G_r(0)·(1 + T_r·s) / (s²/ω_n² + 2ζ·s/ω_n + 1)
```

**2次系で、分子に零点を1つ持つ**という構造そのものが重要です。零点の時定数と、固有振動数・減衰比は、状態方程式の`B`・`tr(A)`・`det(A)`からそのまま決まります。

```text
T_r = m·l_f·V / (l·K_r)
ω_n² = det(A) = l²·K_f·K_r·(1+A_sf·V²) / (m·I_z·V²)
2ζ·ω_n = -tr(A) = [m·(l_f²K_f+l_r²K_r) + I_z·(K_f+K_r)] / (m·I_z·V)
```

`ω_n`・`ζ`が車速`V`の関数であることに注目してください。同じ車がゆっくり走るときと速く走るときで、ヨーの応答特性そのものが変わります。この`V`依存性を実際の時間応答（オーバーシュート・整定時間）に翻訳するのが第5章です。

### FSAEでの動特性指数（仮説として）

Formula SAEの規則はホイールベースの最小値を定めており、乗用車に比べてホイールベース`l`が短くなりがちです。`l`が短いと`l_f·l_r`が小さくなるため、**動特性指数**`k²/(l_f·l_r)`（`k² = I_z/m`、慣性半径の2乗）は乗用車より大きくなりやすいと考えられます。`ω_n² = det(A)`の式に`k²`を代入して整理すると、動特性指数が大きいほど`ω_n`が高くなる方向に効くことが式の形からわかり、理屈のうえでは「ヨーの立ち上がりは速いが、減衰は取りにくい」という傾向が予想されます。

**ただしこれは研究ノートが明示的に「仮説」として扱っている主張であり、本書もそのまま仮説として扱います。** 実車の`I_z`・`l_f`・`l_r`・`K_f`・`K_r`を実測し、定常円旋回試験（第26章）でステップ操舵応答を取ってはじめて検証できることであり、CADから計算しただけの`I_z`や、代表値を当てはめただけの`K_f`・`K_r`では確認したことになりません。自チームの実測でこの傾向が本当に出るかどうかを確かめるところまでが、この節の主張の範囲です。

## 実装

以下のMATLABコードは、次の6つを実装します。base MATLABの機能（`eig`・`det`・`trace`・行列の左除算`\`・`fprintf`・`plot`・ローカル関数）のみを使用しており、追加のToolboxは不要です（Control System Toolboxの`ss`・`tf`・`damp`はあえて使いません。行列演算そのものが見える形にするためです）。

1. `bicycle_A` / `bicycle_ss` — 車両諸元と車速`V`から状態方程式`A, B, C, D`を構築する関数
2. スタビリティファクタ`A_sf`と、特性速度`V_ch`（または臨界速度`V_cr`）・車体すべり角符号反転速度`V_β0`の計算
3. 速度を掃引した固有値による安定性の確認と、固有値軌跡のプロット
4. 定常ゲイン（`r/δ`・`a_y/δ`）を「閉じた式」と「状態方程式を直接解く」の2通りで計算し、一致を確認する単体テスト
5. 符号の健全性チェック：正の舵角がどちら向きのヨーレートを生むはずかを、コードを書く前に手で確認しておきます。ISO 8855は`x`前方・`y`左・`z`上向きの右手系で、正のヨーレート`r`は`+x`から`+y`へ向かう回転（機首が左を向く方向）です。正の舵角`δ`（前輪を左に切る）は、通常の車では機首を左に振る方向、つまり`r>0`を生むはずです。この期待を単体テストで確認します。
6. 過渡応答の零点・固有振動数・減衰比が、状態行列のトレース・行列式の閉じた式と一致することを確認する単体テスト（詳しい時間応答は第5章）

パラメータ`m`・`I_z`・`l_f`・`l_r`・`K_f`・`K_r`はいずれも実測値ではなく、学生フォーミュラ規模でオーダーが合うように置いた仮の値です。自チームの値は第24〜25章の手順（`I_z`はCADではなく振り子試験、`K_f`・`K_r`は第2章の手順）で同定し、差し替えてください。

```matlab
% 線形2自由度バイシクルモデル：状態方程式の構築と基本特性の確認
% ISO 8855: x 前方 / y 左 / z 上向き（第1章の座標系に準拠）
%
% 状態 x = [beta; r]（beta: 車体すべり角[rad], r: ヨーレート[rad/s]）
% 入力 u = delta（前輪実舵角[rad]）
% K_f, K_r は「軸あたり」のコーナリングスティフネス[N/rad]。
% 1輪あたりの C_alpha を使う文献では K = 2*C_alpha（第2章参照）。
%
% base MATLAB のみを使用（Control System Toolbox 不使用）。ss/tf/damp等の
% 状態空間オブジェクトは使わず、A,B,C,D を素の行列として扱い、固有値は
% base の eig()、定常解は行列の左除算(\)で計算する。

clear; clc;

%% 1. 車両諸元（すべて仮の値。実測ではない。第24〜25章で自チームの値に置き換える）
p.m   = 280;      % kg     車両質量+ドライバ（仮定）
p.Iz  = 115;      % kg*m^2 ヨー慣性モーメント（仮定。CADではなく振り子試験で同定すべき。第25章）
p.lf  = 0.79;     % m      重心〜前軸距離（仮定）
p.lr  = 0.76;     % m      重心〜後軸距離（仮定）
p.l   = p.lf + p.lr;   % m  ホイールベース
p.Kf  = 105000;   % N/rad  前軸コーナリングスティフネス（仮定。第2章のK=2*Calphaで積み上げる値）
p.Kr  = 130000;   % N/rad  後軸コーナリングスティフネス（仮定）

fprintf('--- 車両諸元（すべて仮の値、実測ではない） ---\n');
fprintf('m=%.1f kg, Iz=%.1f kg*m^2, lf=%.2f m, lr=%.2f m, l=%.2f m\n', p.m, p.Iz, p.lf, p.lr, p.l);
fprintf('Kf=%.0f N/rad, Kr=%.0f N/rad\n\n', p.Kf, p.Kr);

%% 2. スタビリティファクタ A_sf と特性速度・臨界速度（第4章が解釈する結果）
Asf = -p.m*(p.lf*p.Kf - p.lr*p.Kr) / (p.l^2*p.Kf*p.Kr);
fprintf('--- スタビリティファクタ ---\n');
fprintf('A_sf = %.6e s^2/m^2\n', Asf);
if Asf > 0
    fprintf('A_sf > 0 -> アンダーステア\n');
    Vch = 1/sqrt(Asf);
    fprintf('特性速度 V_ch = 1/sqrt(A_sf) = %.2f m/s (%.1f km/h)\n', Vch, Vch*3.6);
elseif Asf < 0
    fprintf('A_sf < 0 -> オーバーステア\n');
    Vcr = 1/sqrt(-Asf);
    fprintf('臨界速度 V_cr = 1/sqrt(-A_sf) = %.2f m/s (%.1f km/h)\n', Vcr, Vcr*3.6);
else
    fprintf('A_sf = 0 -> ニュートラルステア\n');
end
Vbeta0 = sqrt(p.l*p.lr*p.Kr/(p.m*p.lf));
fprintf('車体すべり角の符号反転速度 V_beta0 = %.2f m/s (%.1f km/h)\n\n', Vbeta0, Vbeta0*3.6);

%% 3. 単体テスト1: 固有値の速度掃引による安定性の確認 + 固有値軌跡のプロット
fprintf('--- 単体テスト1: 固有値の速度掃引（安定性） ---\n');
V_sweep = [5, 10, 15, 20, 25];   % m/s
for V = V_sweep
    A = bicycle_A(p, V);
    ev = eig(A);
    is_stable = all(real(ev) < 0);
    fprintf('V=%5.1f m/s: eig = %+.3f%+.3fi , %+.3f%+.3fi   stable=%d\n', ...
        V, real(ev(1)), imag(ev(1)), real(ev(2)), imag(ev(2)), is_stable);
    assert(is_stable, 'A_sf>0のこのパラメータでは全速度で安定するはず');
end
fprintf('-> A_sf > 0（アンダーステア）のため、掃引した全速度で両固有値の実部が負（安定）。\n\n');

V_plot = 5:0.5:30;
ev_all = zeros(2, numel(V_plot));
for k = 1:numel(V_plot)
    ev_all(:,k) = eig(bicycle_A(p, V_plot(k)));
end
figure;
plot(real(ev_all(1,:)), imag(ev_all(1,:)), '.-'); hold on;
plot(real(ev_all(2,:)), imag(ev_all(2,:)), '.-');
xlabel('Re(\lambda)'); ylabel('Im(\lambda)');
title('固有値の軌跡（V = 5〜30 m/s を掃引）');
legend('\lambda_1', '\lambda_2', 'Location', 'best');
grid on; axis equal;

%% 4. 単体テスト2: 定常ゲインを2通りで計算し一致を確認
fprintf('--- 単体テスト2: 定常ゲイン（閉じた式 vs 状態方程式を直接解く） ---\n');
for V = [10, 20]
    [A, B, C, D] = bicycle_ss(p, V);

    % 方法1: 閉じた式
    r_over_delta_cf  = (V/p.l) / (1 + Asf*V^2);
    ay_over_delta_cf = (V^2/p.l) / (1 + Asf*V^2);

    % 方法2: 定常状態(dx/dt=0)を直接解く。0 = A*x_ss + B*delta -> x_ss = -A\(B*delta)
    delta_test = 1;                 % rad（ゲイン抽出用の単位入力）
    x_ss = -A \ (B*delta_test);
    y_ss = C*x_ss + D*delta_test;

    fprintf('V=%2d m/s: r/delta 閉じた式=%.4f 状態方程式=%.4f | ay/delta 閉じた式=%.4f 出力方程式=%.4f\n', ...
        V, r_over_delta_cf, x_ss(2)/delta_test, ay_over_delta_cf, y_ss(2)/delta_test);

    assert(abs(r_over_delta_cf  - x_ss(2)/delta_test) < 1e-9, 'r/deltaのゲインが2通りで一致しません');
    assert(abs(ay_over_delta_cf - y_ss(2)/delta_test) < 1e-6, 'ay/deltaのゲインが2通りで一致しません');
end
fprintf('-> 2通りの計算が一致（閉じた式と状態方程式の代数が整合）。\n\n');

%% 5. 単体テスト3: 符号の健全性チェック（delta>0 -> rの符号）
fprintf('--- 単体テスト3: delta>0（左操舵, ISO 8855）のときのrの符号 ---\n');
V_test = 15;
[A, B, ~, ~] = bicycle_ss(p, V_test);
delta_test = deg2rad(5);        % 左へ5deg操舵
x_ss = -A \ (B*delta_test);
r_ss = x_ss(2);
fprintf('delta=+%.1f deg -> 定常 r = %+.4f rad/s\n', rad2deg(delta_test), r_ss);
assert(r_ss > 0, 'ISO 8855では正の操舵(左)は正のr(機首が左へヨー)を生むはず');
fprintf('-> delta>0（左操舵）でr>0（機首が左へヨー）。ISO 8855の符号規約と整合。\n\n');

%% 6. 単体テスト4: 過渡応答の構造（omega_n, zeta, T_r）が閉じた式と一致するか（第5章への前振り）
fprintf('--- 単体テスト4: omega_n・zeta・T_r（第5章で詳しく扱う） ---\n');
V_ref = 15;
[A, ~, ~, ~] = bicycle_ss(p, V_ref);
detA = det(A);
trA  = trace(A);
omega_n = sqrt(p.l^2*p.Kf*p.Kr*(1+Asf*V_ref^2) / (p.m*p.Iz*V_ref^2));
two_zeta_omega_n = (p.m*(p.lf^2*p.Kf+p.lr^2*p.Kr) + p.Iz*(p.Kf+p.Kr)) / (p.m*p.Iz*V_ref);
zeta = two_zeta_omega_n / (2*omega_n);
Tr = p.m*p.lf*V_ref / (p.l*p.Kr);

fprintf('det(A)=%.4f, omega_n^2(閉じた式)=%.4f\n', detA, omega_n^2);
fprintf('-trace(A)=%.4f, 2*zeta*omega_n(閉じた式)=%.4f\n', -trA, two_zeta_omega_n);
fprintf('omega_n=%.3f rad/s, zeta=%.3f, T_r=%.5f s (零点 s=%.3f 1/s)\n', omega_n, zeta, Tr, -1/Tr);

assert(abs(detA - omega_n^2) < 1e-6, 'omega_n^2がdet(A)と一致しません');
assert(abs(-trA - two_zeta_omega_n) < 1e-6, '2*zeta*omega_nが-trace(A)と一致しません');
fprintf('-> 状態方程式のtrace/detと、閉じた式(omega_n, zeta, T_r)が一致。\n');
fprintf('   この零点・極が時間応答をどう決めるかは第5章で扱う。\n\n');

%% ローカル関数 -----------------------------------------------------
% 実プロジェクトでは bicycle_ss.m として分割し、第4〜6章・第35章(EKF)・
% 第37章(LQR)・第39章(MPC)から再利用する。

function A = bicycle_A(p, V)
% 状態方程式の係数行列 A（x=[beta;r]）を車速Vで構築する。
    A = [ -(p.Kf+p.Kr)/(p.m*V),            -1 - (p.lf*p.Kf - p.lr*p.Kr)/(p.m*V^2);
          -(p.lf*p.Kf - p.lr*p.Kr)/p.Iz,   -(p.lf^2*p.Kf + p.lr^2*p.Kr)/(p.Iz*V) ];
end

function [A, B, C, D] = bicycle_ss(p, V)
% 線形2輪モデルの状態方程式一式。x=[beta;r], u=delta, y=[r; a_y]。
    A = bicycle_A(p, V);
    B = [ p.Kf/(p.m*V); p.lf*p.Kf/p.Iz ];
    C = [ 0, 1;
          -(p.Kf+p.Kr)/p.m, -(p.lf*p.Kf - p.lr*p.Kr)/(p.m*V) ];
    D = [ 0; p.Kf/p.m ];
end
```

`p.m`・`p.Iz`・`p.lf`・`p.lr`・`p.Kf`・`p.Kr`はいずれも実測値ではなく、学生フォーミュラ規模でオーダーが合うように置いた仮の値です。自分のチームの値で確認する場合は、この仮の値をそのまま使わず、第24〜25章の手順で同定した値に置き換えてください。

## 限界と適用範囲

`ẋ = A·x + Bδ`という線形2輪モデルは、次の前提の上に成り立っています。**この章の価値は、どこで最初に破綻するかを知っていることにあります。** 以下、破綻が早く効くもの（実務上の影響が大きいもの）から順に並べます。

**1. タイヤが線形域にとどまる（横加速度およそ0.3〜0.4g以下）。** これが最も早く、最も広く効く前提です。前章のブラシモデルが示したとおり、横力は`α`とともに無限に増え続けるわけではなく、`μF_z`で頭打ちになります。線形モデルはこの飽和を知りません。**そして学生フォーミュラは常時1g超で走ります。** つまりこの章のモデルは、FSAEが実際に走る領域のほぼ全域で、最初の前提からして外れています。速度域が低くコーナー半径が小さいFSAEは、乗用車以上にこの限界に張り付いた状態で走っているのが実情です。非線形域（限界域の挙動、スピン、カウンターステア）を扱えるようにするのが第7〜11章（タイヤの非線形モデル）と第II部の非線形2輪モデルです。

**2. 左右荷重移動がない。** ARB・ばね定数・ロール剛性配分——FSAEのセットアップで最も頻繁にいじる変数——の効果は、このモデルにはいっさい現れません。「ARBを硬くしたらどうなるか」をこのモデルに聞いても、答えは常に「何も変わらない」です（`K_f`・`K_r`が定数のままだから）。これを扱うのは第13章（荷重移動とロール剛性配分）で、4輪モデル以上が必要です。

**3. 車速`V`が一定。** 制動しながらの旋回、コーナー立ち上がりの加速、LSDが生む駆動時のヨーモーメントは、このモデルの外側です。

**4. `K_f`・`K_r`が定数。** 実車ではタイヤの非線形性と荷重移動により、`K_us`（アンダーステア勾配）は横加速度とともに変化します。「低`a_y`でアンダー、高`a_y`でオーバー」という、セットアップ診断で最も重要な遷移が、この線形モデルには存在しません。第4章で導く`A_sf`は`a_y → 0`の極限値にすぎず、それを一定値として限界域のセットアップ判断に使うことはできません。

**5. 臨界速度`V_cr`を「その速度で必ずスピンする速度」と読まない。** `V_cr`はこの章の`A_sf<0`（オーバーステア）のときにだけ現れる、**開ループ**（舵角固定）での発散速度です。ドライバが閉ループで（ハンドルを戻しながら）安定化していれば、`V_cr`を超えても走れます。逆に`V_cr`以下でも、舵角が大きすぎてタイヤが飽和すればスピンします。線形安定性は限界挙動の必要条件でも十分条件でもありません。

**6. 「単軌道（2輪）モデル」という言葉の罠。** 文献で"single track model"や"bicycle model"という言葉に出会ったとき、それが本章のような4輪車の等価モデルを指しているのか、本物の二輪車（オートバイ）を指しているのかを、必ず確認してください。例えばSharp（1976）の"The Dynamics of Single Track Vehicles"はオートバイの動力学を扱った論文であり、本章のモデルの典拠ではありません。また本章のモデルは、重心が路面高さにあることや車両が質点であることを要求していません——それは単に「左右輪を1本にまとめた4輪車のモデル」であり、そのような追加の仮定は不要です（Guiggiani, 2026）。

**この章のモデルが実際に使える場面。** 上記のとおり、このモデルは「FSAEの限界挙動を予測する」用途にはほとんど使えません。**それでもこの章を丁寧に導出する理由は、次の3つの用途では現役だからです。**

- **用語と設計目標の定義。** ヨーレートゲイン・応答時間・固有振動数・減衰比という「車の応答性」を語るための共通言語そのものが、この章の状態方程式から出てきます。セットアップ変更の方向性（速く曲がりたいのか、落ち着かせたいのか）を、感覚ではなく数値目標として置くための土台になります。
- **状態推定器の内部モデル。** 第35章（拡張カルマンフィルタによる車体すべり角推定）は、直接測れない`β`を、この章の状態方程式と観測可能なヨーレートから推定します。実車はセンサが乏しく（多くはIMU+車輪速のみ）、`β`は推定するしかありません。
- **制御設計の内部モデル。** 第37章（LQR）と第39章（MPC）は、この章の`A`・`B`をそのまま（またはゲインスケジューリングして）予測モデルとして使います。制御則の設計は「モデルが正しい」ことを前提にするのではなく、「モデルが持つ誤差の範囲でロバストに効く」ことを目指すもので、線形モデルの限界を知っていることがその設計そのものの前提になります。

**学生がこの章を読んで持ち帰るべき理解はこうです。「このモデルは自分の車が限界でどう動くかを教えてくれない。それでも、車の応答性を数値で語り、状態推定器や制御則の内部モデルとして働く。」** この2つを取り違えると——つまりこのモデルの出力を限界挙動の予測だと思ってしまうと——それはこの章の説明が不十分だったということです。次の階層（非線形タイヤ、荷重移動）に進むべき条件と、この章が扱わなかったものの完全な地図は第6章で示します。

## 学生チームでの現実解

1. **自チームの`m`・`I_z`・`l_f`・`l_r`を実測する。** 特に`I_z`はCADの値をそのまま使わないでください。振り子試験（三線式トリフィラーなど、第25章）で同定した`I_z`と、CADだけで出した`I_z`は10%程度食い違うことが珍しくなく、`I_z`の10%誤差は固有振動数`ω_n`に約5%の誤差として直接効きます（`ω_n ∝ 1/√I_z`）。ドライバ交代で重心位置・`I_z`が変わることも忘れないでください（第25章）。
2. **`K_f`・`K_r`は第2章の手順で入手した値を使う。** TTCデータ、定常円旋回試験からの逆算、接地痕実測のいずれでも構いませんが、「仮の値」であることを常にコードとWikiに明記してください。
3. **本章のMATLABコードの`p`をそのまま自チームの値に置き換えて実行し、`V_ch`（または`V_cr`）を自チームの最高速と比べる。** もし計算した`V_ch`や`V_cr`が自チームの実用速度域に近い値なら、パラメータの入力ミス（単位の取り違え、`K_f`と`K_r`の前後逆転など）をまず疑ってください。通常のFSAE車では`A_sf`が小さく`V_ch`が実用速度域よりずっと高い（＝この章の`V`依存性が実用域にはほとんど効かない）結果になりやすいはずです。
4. **このモデルの出力をセットアップ判断（ARB・ばね・空力）に使わない。** ここまで繰り返した通り、このモデルには左右荷重移動がありません。セットアップの意思決定に使ってよいのは第13章以降の4輪モデルです。この章の`A_sf`やゲインは、あくまで「用語の定義」「制御設計の目標値」として使ってください。
5. **定常円旋回試験（第26章）で、`K_us`が`a_y`とともにどう変わるかを実測する。** この章の`K_f`・`K_r`一定という前提がどこで崩れるか、そして「動特性指数が高いほどヨーの立ち上がりが速く減衰が取りにくい」という本章の仮説が自分の車で成立するかは、この実測でしか確認できません。
6. **今すぐ試せる最初のステップ：** 本章のMATLABコードの`p.m`・`p.Iz`・`p.lf`・`p.lr`・`p.Kf`・`p.Kr`を、自チームの現在のベストな推定値（暫定値でも構いません）に置き換えて実行し、`A_sf`の符号（アンダー/オーバー/ニュートラル）と、`V_ch`または`V_cr`の値を確認してください。そのうえで、`K_f`と`K_r`を意図的に入れ替えたときに`A_sf`の符号がどう反転するか、`I_z`を2倍にしたときに`ω_n`がどう変わるかを、手を動かして確かめてみてください。次章（定常円旋回とスタビリティファクタ）に進む前に、この章の状態方程式の中身が自分の手で再現できる、という感覚を持っておくことが重要です。
