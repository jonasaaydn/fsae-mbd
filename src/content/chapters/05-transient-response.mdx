## この章でできるようになること

- 第4章の定常解（`ẋ=0`）が答えない問い——「その定常値にどれだけの速さでたどり着くか」——を、具体的な走行状況で言葉にできる。
- 伝達関数`r(s)/δ(s)`が零点を1つ持つ2次系になることを、第3章の状態方程式`A`・`B`からCramerの公式で自分の手で導出でき、分母が`s² − tr(A)·s + det(A)`、零点が`s = −1/T_r`になることを確認できる。
- `2ζ·ω_n = −tr(A)`という式の符号が正しいこと（`tr(A)`が常に負だから`−tr(A)`は常に正、という第3章の事実との整合）を、暗記ではなく確認の手順として説明できる。
- `ω_n(V)`・`ζ(V)`がともに車速`V`の増加とともに単調に減少することを、閉じた式`ζ(V) = C/√(1+A_sf·V²)`を自分で導出したうえで示せる。
- `A_sf<0`（オーバーステア）のとき`ω_n² → 0`となる速度が、第4章の臨界速度`V_cr`と一致することを、数値例で確認できる。
- ステップ操舵応答の立ち上がり時間・ピーク・オーバーシュート・整定時間を計算し、「素直な応答」と「神経質な応答」を数値で区別できる。
- 零点の物理的な由来（フロントタイヤの横力は舵角に即座に反応するが、リアタイヤの横力は状態量`β`・`r`を介してしか効かず遅れて追随する）を、入力行列`B`の成分から説明できる。
- 車体すべり角`β`の過渡応答が、ヨーレートと同じ極を持ちながら異なる零点を持つこと、そしてある速度を境に零点が右半平面に移り、定常値と逆向きに一瞬振れる現象が起こりうることを知っている。
- ステップステア試験で何を測定し、この章の`ω_n`・`ζ`・立ち上がり時間と何を比較すべきかを言え、この章の応答時間が「設計目標・制御器の目安」としては使えるが「限界挙動の予測」には使えない理由を説明できる。

## なぜ必要か

第4章は`ẋ = 0`とおいて、舵を切ってから十分時間が経ったあとに車がどこに落ち着くか——定常ヨーレートゲイン`r/δ`、スタビリティファクタ`A_sf`——を扱いました。しかし「どこに落ち着くか」だけでは、車の応答性を語ったことになりません。次の2台を比べてみてください。

- **車A：** 舵を切ってから0.03秒でほぼ目標のヨーレートに達し、行き過ぎることなくそこに留まる。
- **車B：** 車Aとまったく同じ`r/δ`（定常ゲイン）を持つが、目標に達するまで0.08秒かかり、しかも一瞬目標を追い越してから戻ってくる。

第4章の道具（`A_sf`・`r/δ`）だけでは、この2台をまったく区別できません。**定常ゲインが同じでも、そこに至る経路（速さ・行き過ぎの有無）はまったく別の量で決まる**からです。ところがレースでは、この「経路」こそが勝敗を分けます。パイロンを立てたスラローム（連続した切り返し）や、シケインでの素早い方向転換を考えてください。ドライバーが舵を切ってから車が実際に向きを変え始めるまでの遅れ、向きを変え終えるまでの時間——これらはコーナーの定常円旋回部分にはほとんど無関係で、**過渡応答**（transient response）そのものの性質で決まります。定常状態に到達する前に次の操作が始まるようなセクションでは、そもそも定常ゲインが実際のヨーレートとして現れる時間すら存在しません。

この章がすることは、第3章の終わりに構造だけ示した伝達関数`r(s)/δ(s)`——零点を1つ持つ2次系——を、実際に時間領域の量（立ち上がり時間・オーバーシュート・整定時間）として解析することです。使う道具は第3章の状態方程式の`A`・`B`だけで、新しい仮定は何も追加しません。第4章が`ẋ=0`とおいて「捨てた」過渡項を、この章で取り戻します。

## 理論

### 伝達関数`r(s)/δ(s)`の導出：零点を1つ持つ2次系

第3章の状態方程式`ẋ = A·x + Bδ`（`x=[β,r]ᵀ`）をラプラス変換すると`sX(s) = A·X(s) + Bδ(s)`、すなわち`X(s) = (sI−A)⁻¹·B·δ(s)`です。ヨーレート`r`は状態の第2成分なので、`r(s)/δ(s) = [0 1]·(sI−A)⁻¹·B`という1本の式で書けます。

2×2行列の逆行列は`(sI−A)⁻¹ = adj(sI−A) / det(sI−A)`で、`adj(sI−A) = [[s−A22, A12], [A21, s−A11]]`です。これを使うと

```text
r(s)/δ(s) = [A21·B1 + (s−A11)·B2] / det(sI−A)
          = [A21·B1 + B2·s − A11·B2] / (s² − tr(A)·s + det(A))
```

となります（`det(sI−A) = s² − tr(A)·s + det(A)`は特性方程式そのものです）。第3章の`A11, A12, A21, A22, B1, B2`をそのまま代入して分子を整理すると（途中の展開はここでは省略しますが、自分の手で追うことを強く勧めます）、

```text
分子 = (l_f·K_f/I_z)·s + K_f·K_r·l/(I_z·m·V)
     = (l_f·K_f/I_z)·(s + l·K_r/(m·l_f·V))
```

という形にまとまります。零点（分子がゼロになる`s`）は`s = −l·K_r/(m·l_f·V) = −1/T_r`、すなわち

```text
T_r = m·l_f·V / (l·K_r)
```

です。分母を`ω_n²`で割って標準形に直すと、第3章の終わりに示した

```text
r(s)/δ(s) = G_r(0)·(1 + T_r·s) / (s²/ω_n² + 2ζ·s/ω_n + 1)
```

が得られます（`s=0`とおいたときのこの式の値が、第4章で導いた定常ゲイン`(V/l)/(1+A_sf·V²)`に一致することも代数的に確認できます——実装セクションのコードで数値的に確認します）。**2次系（分母が`s`の2次式）で、分子に零点を1つ持つ**という構造そのものが、この章の出発点です。

### 零点の物理的な意味：フロントは即座に、リアは遅れて

零点の係数`l_f·K_f/I_z`は、第3章の入力行列`B`の第2成分（`ṙ`への`δ`の直接の効き方）とまったく同じ量です。これは偶然ではありません。舵角`δ`が変化した瞬間、**フロントタイヤのスリップ角`α_f = β + l_f·r/V − δ`は`δ`を通じて即座に変化し**、その分の横力`K_f·δ`がヨー角加速度`ṙ`に直接効きます（`B`行列を通じた直達項）。一方、**リアタイヤの横力は状態量`β`・`r`を通じてしか変化しません**——`α_r = β − l_r·r/V`には`δ`が直接現れないからです。`β`と`r`が実際に変化するには、微分方程式`ẋ=Ax+Bδ`に従って時間がかかります。

つまり、フロントタイヤの反応は「即座」、リアタイヤの反応は「状態量を介した遅れ」という非対称性が、この系にはもともと組み込まれています。この非対称性が伝達関数の零点として現れ、結果として`r(t)`の応答は、ゆっくり極（`ω_n`・`ζ`で決まる2次系の応答）に追いつこうとする成分に、フロント由来の速い成分が上乗せされた形になります。零点が原点に近い（`T_r`が大きい）ほどこの「上乗せ」は強く効き、極だけなら`ζ≥1`で行き過ぎないはずの応答にも、行き過ぎ（オーバーシュート）を生むことがあります。**「フロントは即座に反応し、リアは遅れて追いつく」というこの非対称性こそが、ヨーレート応答が定常値を一瞬追い越してから戻ってくる理由です。**

### `2ζ·ω_n = −tr(A)`の符号を確認する

`ω_n²`・`2ζ·ω_n`は分母の係数から

```text
ω_n² = det(A) = l²·K_f·K_r·(1+A_sf·V²) / (m·I_z·V²)
2ζ·ω_n = −tr(A) = [m·(l_f²·K_f+l_r²·K_r) + I_z·(K_f+K_r)] / (m·I_z·V)
```

と決まります。ここで一度立ち止まって符号を確認します。第3章は「`tr(A)`は`m, I_z, V, K_f, K_r`が正である限り常に負」と示しました。したがって`−tr(A)`は常に正です。一方`2ζ·ω_n`は、`ζ>0`（安定な減衰系）かつ`ω_n>0`（実数の固有振動数）である限り、これも常に正の量です。**正の量と正の量が等号で結ばれているので、符号は矛盾しません。** これは自明に見えるかもしれませんが、`2ζ·ω_n = tr(A)`（符号反転）と書いてしまう間違いは実際に起こりえます——その場合`tr(A)<0`なので左辺は「`ζ>0`なら正」のはずが右辺は負になり、符号が矛盾するはずです。この矛盾が起きていないことを、実装セクションのコードで具体的な数値により確認します。

### `ω_n`・`ζ`の速度依存性を導出する

`ω_n²(V) = (l²K_fK_r/(mI_z))·(1/V² + A_sf)`と書き直せます。`1/V²`は`V`の増加とともに単調に減少するので、`ω_n²(V)`も（`A_sf`の符号によらず）**`V`の増加とともに単調に減少**します。`A_sf>0`（アンダーステア）の場合、`V→∞`で`ω_n²`はゼロにはならず、正の値`l²K_fK_r·A_sf/(m·I_z)`に漸近します——アンダーステア車は原理的にどんな速度でも安定である（第3〜4章）ことと整合しています。

`ζ(V)`についても閉じた式が導けます。`2ζ·ω_n`は`1/V`に比例する量、`ω_n`は`√(1/V²+A_sf)`に比例する量なので、両者の比`ζ = (2ζω_n)/(2ω_n)`から`V`の依存性を計算すると

```text
ζ(V) = C / √(1 + A_sf·V²)      ,      C = [I_z·(K_f+K_r) + m·(l_f²K_f+l_r²K_r)] / (2·l·√(m·I_z·K_f·K_r))
```

という形にまとまります（`C`は`V`に依存しない定数）。`A_sf>0`のとき分母`√(1+A_sf·V²)`は`V`とともに単調に増加するので、**`ζ(V)`も`V`の増加とともに単調に減少**します。`ω_n`も`ζ`も速度とともに落ちるので、**車は速く走るほど、ヨーの応答が遅くなり（`ω_n`低下）、かつ減衰が効きにくくなる（`ζ`低下）**という、この章の中心的な主張が、2本の閉じた式から直接出てきます。実装セクションでこの`C`の値と、`ζ(V)=1`になる交差速度`V*`を実際に計算します。

### 安定条件との接続：`ω_n² → 0`が`V_cr`そのものであること

`A_sf<0`（オーバーステア）の場合、`ω_n²(V) = (l²K_fK_r/(mI_z))·(1/V²+A_sf)`は`V`の増加とともに単調に減少し続け、`1/V² = −A_sf`となる速度、すなわち

```text
V = 1/√(−A_sf) = V_cr
```

で**ちょうどゼロを通過**します。これは第3〜4章で導いた臨界速度`V_cr`（ヨーレートゲインが発散し、`det(A)>0`の安定条件が破れる速度）と完全に同じ式です。つまり、第4章では「ゲインが発散する速度」として現れた`V_cr`は、この章の言葉では「**固有振動数がゼロになる速度**」として同じ場所に現れます。`ω_n=0`は「ヨーの復元力が失われる」ことを意味し、`V_cr`を超えると`ω_n²<0`（複素数の`ω_n`）となって2次系としての意味を失い、実際には固有値の一方が正の実数（不安定な発散モード）に転じます。この数値的な確認は実装セクションで行います。

### ステップ操舵応答の指標

一定舵角を（理想的には瞬時に）与える**ステップ操舵応答**は、この章の`ω_n`・`ζ`・`T_r`を実際の時間の量に変換して評価するための標準的な方法です。以下の4つの指標を使います。

- **立ち上がり時間（rise time）：** 定常値の10%から90%に達するまでの時間。応答の「速さ」の代表的な指標です。
- **ピーク（peak）とオーバーシュート（overshoot）：** 応答が定常値を追い越す場合、その最大値とその時刻。オーバーシュートは`(ピーク値−定常値)/定常値`のパーセントで表します。前節で見た零点の効果により、たとえ極だけなら`ζ≥1`で行き過ぎないはずの速度でも、零点の寄与で小さな行き過ぎが生じることがあります。
- **整定時間（settling time）：** 応答が定常値の±2%の帯に入ってから二度と出ない時刻。

これらはいずれも解析的な閉じた式（極だけの2次系なら教科書的な近似式がありますが、この系は零点を持つため単純な式には収まりません）よりも、状態方程式を直接時間積分して求めるほうが確実で、誤りが少なくなります。実装セクションでは、この積分をControl System Toolboxの`step`に頼らず、自作の固定ステップRK4で行います。

### 車体すべり角`β`の過渡応答：同じ極、違う零点

`β(s)/δ(s)`も同じ手順（`[1 0]·(sI−A)⁻¹·B`）で求まり、**`r(s)/δ(s)`とまったく同じ分母（同じ極、同じ`ω_n`・`ζ`）**を持ちます——当然です。どちらも同じ状態方程式`A`から出てくる応答だからです。しかし零点は異なり、`β(s)/δ(s)`の零点は

```text
s_β = [m·l_f·V² − K_r·l·l_r] / (I_z·V)
```

となります（第3章の`A`・`B`から同じCramerの手順で導けます）。ここで注目すべきは、この零点がゼロになる速度——分子`m·l_f·V² − K_r·l·l_r = 0`を解いた速度——が

```text
V = √(l·l_r·K_r / (m·l_f)) = V_β0
```

と、**第4章で導いた「車体すべり角の符号反転速度`V_β0`」とまったく同じ式**になることです。`V < V_β0`では零点`s_β`は負（安定な零点）、`V > V_β0`では零点`s_β`は正——**右半平面の零点**になります。右半平面の零点を持つ系は非最小位相系と呼ばれ、典型的な症状は「最終的な定常値と逆方向に、過渡の初期だけ振れてから戻る」という挙動です。つまり`V>V_β0`では、**定常的には内向き（`β<0`）に収束するはずの車体が、ステップ操舵の直後は一瞬外向き（`β>0`）に振れてから、内向きに反転して収束する**ことが理論的に予想されます。これを実装セクションのシミュレーションで確認します。ドライバーはヨーレートだけでなく車体すべり角（お尻の横滑り感覚）も感じ取るので、この一瞬の逆方向の動きは、高速域でステアリングを切った瞬間の「一瞬お尻が外に出る」ような感覚として体感されている可能性があります——ただしこれは線形モデルの予測であり、実車での体感の言語化とは別に検証が必要な主張です。

### FSAEでの動特性指数（第3章の仮説の継続）

第3章は、FSAEはホイールベースが短いため動特性指数`k²/(l_f·l_r)`（`k²=I_z/m`）が大きくなりやすく、理屈のうえでは`ω_n`が高くなる方向に効くという仮説を示しました。この章の実装セクションで計算する数値例では、実際に`ω_n`が数十rad/s（数Hz〜十数Hz）という、乗用車の文献値（おおむね1桁のrad/s）と比べてかなり高い値になります。**ただしこれは第3章と同じ仮のパラメータから出てくる数値であり、この章はこの仮説を追加で検証するものではありません。** 高い`ω_n`が実際にFSAE車の特徴なのか、それとも本書の仮パラメータがたまたまそうなっているだけなのかは、自チームの実測（`I_z`の振り子試験、`K_f`・`K_r`の同定、第25〜26章）でしか確かめられません。

## 実装

以下のMATLABコードは、次の7つを実装します。base MATLABの機能（`det`・`trace`・`sqrt`・`deg2rad`・匿名関数・`fprintf`・`plot`・`yyaxis`・ローカル関数）のみを使用しており、追加のToolboxは不要です。**Control System Toolboxの`tf`・`step`・`damp`はあえて使いません。** ステップ応答は状態方程式を自分で固定ステップRK4積分して作り、`ω_n`・`ζ`は`det(A)`・`trace(A)`から直接計算します。パラメータは第3〜4章と同じ仮の値を使います。

1. `bicycle_A`/`bicycle_B` — 第3章と同じ状態方程式の係数行列を車速`V`から構築する関数
2. 単体テスト1：`ω_n² = det(A)`・`2ζ·ω_n = −tr(A)`が閉じた式と一致すること、`tr(A)<0`ゆえ`−tr(A)>0`という符号を明示的に確認する単体テスト
3. 単体テスト2：`ζ(V) = C/√(1+A_sf·V²)`という閉じた式が、`det(A)`・`trace(A)`由来の`ζ`と一致することを確認し、`ζ=1`になる交差速度`V*`を計算する単体テスト
4. 参考：`K_f`と`K_r`を入れ替えた仮のオーバーステア車で、`ω_n² → 0`が`V_cr`とちょうど一致することを確認する数値例（この章の主題の車ではない）
5. `step_response_rk4` — 状態方程式をステップ入力に対して自作の固定ステップRK4で積分する関数。定常値がRK4の最終値と第4章の閉じた式で一致することを確認する単体テスト
6. `step_metrics` — 立ち上がり時間・ピーク・オーバーシュート・整定時間を計算する関数
7. `β`の過渡が`V_β0`を超える速度で定常値と逆向きに振れることを確認する単体テストと、速度掃引による`ω_n`・`ζ`・`T_r`・応答時間の一覧表・プロット

```matlab
% 過渡応答：omega_n・zeta・T_r の速度依存性とステップ操舵応答（自作RK4）
% ISO 8855: x 前方 / y 左 / z 上向き（第1章の座標系に準拠）
%
% 状態 x = [beta; r]（beta: 車体すべり角[rad], r: ヨーレート[rad/s]）
% 入力 u = delta（前輪実舵角[rad]）
% K_f, K_r は「軸あたり」のコーナリングスティフネス[N/rad]（第2章）。
%
% base MATLAB のみを使用。tf/step/damp（Control System Toolboxが必要）は使わず、
% 状態方程式を自分でRK4積分してステップ応答を作る。omega_n・zetaはdet(A)/trace(A)
% から直接計算する。

clear; clc;

%% 1. 車両諸元（第3〜5章で共通の仮の値。実測ではない）
p.m   = 280;      % kg     車両質量+ドライバ（仮定）
p.Iz  = 115;      % kg*m^2 ヨー慣性モーメント（仮定）
p.lf  = 0.79;     % m      重心〜前軸距離（仮定）
p.lr  = 0.76;     % m      重心〜後軸距離（仮定）
p.l   = p.lf + p.lr;   % m  ホイールベース
p.Kf  = 105000;   % N/rad  前軸コーナリングスティフネス（仮定）
p.Kr  = 130000;   % N/rad  後軸コーナリングスティフネス（仮定）

fprintf('--- 車両諸元（第3〜5章と同じ仮の値、実測ではない） ---\n');
fprintf('m=%.1f kg, Iz=%.1f kg*m^2, lf=%.2f m, lr=%.2f m, l=%.2f m\n', p.m, p.Iz, p.lf, p.lr, p.l);
fprintf('Kf=%.0f N/rad, Kr=%.0f N/rad\n\n', p.Kf, p.Kr);

Asf = -p.m*(p.lf*p.Kf - p.lr*p.Kr) / (p.l^2*p.Kf*p.Kr);
fprintf('A_sf = %.6e s^2/m^2（第3〜4章と同一。>0なのでアンダーステア）\n\n', Asf);

%% 2. 単体テスト1: omega_n^2 = det(A), 2*zeta*omega_n = -trace(A)（符号を明示的に確認）
% trace(A) は第3章で「常に負」と示した。よって -trace(A) は常に正であり、
% 2*zeta*omega_n（zeta>0, omega_n>0の積の2倍）と符号が一致するはずである。
% これを「確認して終わり」にせず、実際に数値で突き合わせる。
fprintf('--- 単体テスト1: omega_n^2=det(A), 2*zeta*omega_n=-trace(A) の符号・数値確認 ---\n');
for V = [10, 15, 20, 25, 30, 35]
    A = bicycle_A(p, V);
    detA = det(A);
    trA  = trace(A);
    [omega_n, zeta, Tr] = transient_closed_form(p, Asf, V);

    assert(trA < 0, 'trace(A)が負であるという第3章の主張が崩れている');
    assert(-trA > 0, '-trace(A)は正のはず（2*zeta*omega_nと符号が合わない）');
    assert(abs(detA - omega_n^2) < 1e-6*max(1,abs(detA)), ...
        'omega_n^2がdet(A)と一致しません');
    assert(abs(-trA - 2*zeta*omega_n) < 1e-6*max(1,abs(trA)), ...
        '2*zeta*omega_nが-trace(A)と一致しません（符号ミスの疑い）');

    fprintf('V=%5.1f m/s: det(A)=%9.3f  omega_n^2(閉形)=%9.3f | -trace(A)=%8.4f  2*zeta*omega_n(閉形)=%8.4f\n', ...
        V, detA, omega_n^2, -trA, 2*zeta*omega_n);
    fprintf('             omega_n=%7.3f rad/s (%.2f Hz)  zeta=%.5f  T_r=%.5f s\n', ...
        omega_n, omega_n/(2*pi), zeta, Tr);
end
fprintf('-> 全速度で一致。2*zeta*omega_n=-trace(A)の符号エラーは無い。\n\n');

%% 3. zeta(V) の閉じた式を導出・検証: zeta(V) = C / sqrt(1 + A_sf*V^2)
C_zeta = (p.Iz*(p.Kf+p.Kr) + p.m*(p.lf^2*p.Kf+p.lr^2*p.Kr)) / (2*p.l*sqrt(p.m*p.Iz*p.Kf*p.Kr));
fprintf('--- 単体テスト2: zeta(V) 閉じた式 C/sqrt(1+A_sf*V^2) の検証 ---\n');
fprintf('C = %.6f\n', C_zeta);
for V = [10, 20, 30]
    [~, zeta_ref, ~] = transient_closed_form(p, Asf, V);
    zeta_formula = C_zeta / sqrt(1+Asf*V^2);
    fprintf('V=%5.1f: zeta(det/trace由来)=%.6f  zeta(C式)=%.6f\n', V, zeta_ref, zeta_formula);
    assert(abs(zeta_ref - zeta_formula) < 1e-9, 'zeta(V)の閉じた式が一致しません');
end
V_cross = sqrt((C_zeta^2 - 1)/Asf);
fprintf('-> 一致。zeta=1の交差速度 V* = %.3f m/s (%.1f km/h)。\n', V_cross, V_cross*3.6);
fprintf('   V<V*で過減衰（オーバーシュート無し）、V>V*で過小減衰（オーバーシュート有り）。\n\n');

%% 4. オーバーステア車の例（仮にKfとKrを入れ替えた場合）でomega_n^2->0がV_crと一致することを確認
% 注意: これはこの章の主人公の車ではない。A_sf<0（オーバーステア）の場合に
% 第4章の臨界速度V_crのところでomega_n^2がちょうどゼロになることを示すための、
% この節だけの仮の数値例（KfとKrを入れ替えただけ）。
p_over = p;
p_over.Kf = p.Kr;   % 前後を入れ替えただけの仮の例（この章の車の値ではない）
p_over.Kr = p.Kf;
Asf_over = -p_over.m*(p_over.lf*p_over.Kf - p_over.lr*p_over.Kr) / (p_over.l^2*p_over.Kf*p_over.Kr);
fprintf('--- 参考: オーバーステア例（Kf・Krを入れ替えた仮の車、この章の主題ではない） ---\n');
fprintf('A_sf(仮) = %.6e (<0 のでオーバーステア)\n', Asf_over);
Vcr = 1/sqrt(-Asf_over);
fprintf('V_cr = 1/sqrt(-A_sf) = %.3f m/s\n', Vcr);
for V = [Vcr-5, Vcr, Vcr+5]
    detA_over = p_over.l^2*p_over.Kf*p_over.Kr*(1+Asf_over*V^2) / (p_over.m*p_over.Iz*V^2);
    fprintf('V=%6.2f m/s: 1+A_sf*V^2=%+.5f  omega_n^2=det(A)=%+9.3f\n', V, 1+Asf_over*V^2, detA_over);
end
assert(abs((1+Asf_over*Vcr^2)) < 1e-9, 'V_crでomega_n^2がゼロになっていません');
fprintf('-> V_crでomega_n^2がちょうどゼロを通過し、その先は虚数（不安定）になる。\n');
fprintf('   これは第3〜4章のdet(A)>0の安定条件と同じ1つの条件の別の見え方。\n\n');

%% 5. ステップ操舵応答：自作RK4で積分（Control System Toolboxのstepは使わない）
delta_step_deg = 2.0;         % deg  ステップ操舵角（仮）
delta_step = deg2rad(delta_step_deg);
dt = 0.0005;                  % s    固定ステップ
t_end = 0.5;                  % s

fprintf('--- ステップ操舵応答（delta=%.1f deg ステップ, RK4, dt=%.4f s） ---\n', delta_step_deg, dt);
V_list = [15, 35];   % 「素直」な例と「神経質」な例
labels = {'V=15 m/s（zeta>1寄り、素直）', 'V=35 m/s（zeta<1、オーバーシュート有り）'};
for k = 1:numel(V_list)
    V = V_list(k);
    [t, r, beta] = step_response_rk4(p, V, delta_step, dt, t_end);

    r_ss   = (V/p.l)/(1+Asf*V^2) * delta_step;
    beta_ss = (1 - p.m*p.lf*V^2/(p.l*p.lr*p.Kr))*(p.lr/p.l)/(1+Asf*V^2) * delta_step;

    m1 = step_metrics(t, r, r_ss);

    fprintf('%s\n', labels{k});
    fprintf('  r_ss(第4章の閉じた式)=%.5f rad/s | r(t_end)(RK4)=%.5f rad/s | 差=%.3e\n', ...
        r_ss, r(end), abs(r_ss-r(end)));
    assert(abs(r_ss - r(end)) < 1e-6*max(1,abs(r_ss)), ...
        'RK4の最終値が第4章の定常ゲインと一致しません');
    fprintf('  立ち上がり時間(10-90%%)=%.1f ms | ピーク=%.5f rad/s (t=%.1f ms) | オーバーシュート=%.3f%%\n', ...
        m1.t_rise*1e3, m1.y_peak, m1.t_peak*1e3, m1.overshoot_pct);
    fprintf('  整定時間(±2%%)=%.1f ms\n', m1.t_settle*1e3);
    fprintf('  beta_ss(第4章の閉じた式)=%+.5f rad | beta(t_end)(RK4)=%+.5f rad | 差=%.3e\n\n', ...
        beta_ss, beta(end), abs(beta_ss-beta(end)));
end
fprintf('-> RK4の最終値は、両方の速度で第4章の定常ゲインに一致（誤差は積分打ち切り誤差のみ）。\n\n');

%% 6. beta の過渡が定常値と逆向きに振れる例（V_beta0 付近、右半平面零点）
Vbeta0 = sqrt(p.l*p.lr*p.Kr/(p.m*p.lf));
fprintf('--- betaの過渡：V_beta0=%.2f m/s を超えると零点が右半平面に入り、初期に逆向きへ振れる ---\n', Vbeta0);
V = 35;   % > V_beta0
[t, r, beta] = step_response_rk4(p, V, delta_step, dt, 0.15);
[beta_max, idx_max] = max(beta);
beta_ss = (1 - p.m*p.lf*V^2/(p.l*p.lr*p.Kr))*(p.lr/p.l)/(1+Asf*V^2) * delta_step;
fprintf('V=%.1f m/s (>V_beta0=%.2f): beta_ss(定常)=%+.5f rad, betaの初期最大値=%+.5f rad (t=%.1f ms)\n', ...
    V, Vbeta0, beta_ss, beta_max, t(idx_max)*1e3);
assert(beta_ss < 0 && beta_max > 0, ...
    'V>V_beta0でbeta_ssが負・betaの初期ピークが正という逆向きの振れが確認できません');
fprintf('-> 定常値は負（内向き）だが、過渡初期には正（外向き）へ一瞬振れてから反転する。\n\n');

%% 7. 速度掃引：omega_n・zeta・T_r・応答時間の一覧表 + プロット
V_sweep = [5 10 15 18 20 25 30 35];
omega_n_sweep = zeros(size(V_sweep));

%% ローカル関数 -----------------------------------------------------

function A = bicycle_A(p, V)
% 状態方程式の係数行列 A（x=[beta;r]）を車速Vで構築する（第3章と同一）。
    A = [ -(p.Kf+p.Kr)/(p.m*V),            -1 - (p.lf*p.Kf - p.lr*p.Kr)/(p.m*V^2);
          -(p.lf*p.Kf - p.lr*p.Kr)/p.Iz,   -(p.lf^2*p.Kf + p.lr^2*p.Kr)/(p.Iz*V) ];
end

function B = bicycle_B(p, V)
% 入力行列 B（第3章と同一）。
    B = [ p.Kf/(p.m*V); p.lf*p.Kf/p.Iz ];
end

function [omega_n, zeta, Tr] = transient_closed_form(p, Asf, V)
% 過渡応答の閉じた式（理論の節で導出）。omega_n^2=det(A), 2*zeta*omega_n=-trace(A)。
    omega_n2 = p.l^2*p.Kf*p.Kr*(1+Asf*V^2) / (p.m*p.Iz*V^2);
    two_zeta_omega_n = (p.m*(p.lf^2*p.Kf+p.lr^2*p.Kr) + p.Iz*(p.Kf+p.Kr)) / (p.m*p.Iz*V);
    omega_n = sqrt(omega_n2);
    zeta = two_zeta_omega_n / (2*omega_n);
    Tr = p.m*p.lf*V / (p.l*p.Kr);
end

function [t, r, beta] = step_response_rk4(p, V, delta_step, dt, t_end)
% 状態方程式 xdot = A*x + B*delta を、ステップ入力deltaに対して固定ステップRK4で積分する。
% x(0)=[0;0]（静止状態からのステップ）。Control System Toolboxのstep/lsimは使わない。
    A = bicycle_A(p, V);
    B = bicycle_B(p, V);
    n = round(t_end/dt);
    t = (0:n)'*dt;
    x = [0; 0];
    beta = zeros(n+1,1);
    r = zeros(n+1,1);
    for k = 1:n
        f = @(xx) A*xx + B*delta_step;
        k1 = f(x);
        k2 = f(x + dt/2*k1);
        k3 = f(x + dt/2*k2);
        k4 = f(x + dt*k3);
        x = x + dt/6*(k1 + 2*k2 + 2*k3 + k4);
        beta(k+1) = x(1);
        r(k+1) = x(2);
    end
end

function s = step_metrics(t, y, y_ss)
% 立ち上がり時間(10-90%)・ピーク・オーバーシュート・整定時間(±2%)を計算する。
    idx10 = find(y >= 0.1*y_ss, 1, 'first');
    idx90 = find(y >= 0.9*y_ss, 1, 'first');
    if isempty(idx10) || isempty(idx90)
        s.t_rise = NaN;
    else
        s.t_rise = t(idx90) - t(idx10);
    end
    [y_peak, idx_peak] = max(y);
    s.y_peak = y_peak;
    s.t_peak = t(idx_peak);
    s.overshoot_pct = (y_peak - y_ss)/y_ss*100;
    band = 0.02*abs(y_ss);
    outside = find(abs(y - y_ss) > band);
    if isempty(outside)
        s.t_settle = 0;
    else
        s.t_settle = t(outside(end));
    end
end
```

`p.m`・`p.Iz`・`p.lf`・`p.lr`・`p.Kf`・`p.Kr`はいずれも実測値ではなく、第3〜4章と同じ仮の値です。自分のチームの値で確認する場合は、第24〜25章の手順で同定した値に置き換えてください。

## 限界と適用範囲

この章の`ω_n`・`ζ`・`T_r`・立ち上がり時間・オーバーシュート・整定時間は、すべて第3章の8つの前提——特にタイヤの線形性（横加速度およそ0.3〜0.4g以下）、左右荷重移動なし、速度一定——の上に成り立っています。過渡応答を扱うこの章には、それに加えてさらに2つの重要な限界があります。

**1. タイヤの過渡遅れ（緩和長）が入っていない。** この章の状態方程式は、タイヤの横力がスリップ角の変化に**瞬時に**追従すると仮定しています。実際のタイヤは、スリップ角が変化してから横力が新しい値に落ち着くまでに、走行距離にしておよそ1タイヤ半径程度の遅れ（緩和長、relaxation length）を持ちます（Pacejka, 2012；第2章でも触れた「過渡遅れは時間ではなく走行距離で決まる」という性質です）。この効果は第7章で緩和長として定式化しますが、**この章の`T_r`・`ω_n`・`ζ`にはいっさい含まれていません。** つまり、この章が計算する応答時間は、実車の応答時間より**必ず楽観側**（実際より速い）に出ます。実車の応答はこの章の計算値に、緩和長由来の追加の遅れが上乗せされたものになります。

**2. 荷重移動がないので、ロールによる減衰の変化を表現できない。** 第3章の前提のとおり、この章のモデルには左右荷重移動もロール運動もありません。実車ではロールの過渡（ばね・ダンパ・ARBの動特性）がヨーの過渡と連成し、ダンパのセッティングがヨーの減衰の効き方そのものを変えます。この章の`ζ`は、あくまで「ロールが無いとみなした場合の」減衰比であり、**ダンパチューニングがヨー応答をどう変えるかをこの章から読み取ることはできません。** これを扱うには14自由度モデル（上下・ロール自由度を持つ階層）が必要です。

**この章の応答時間は何に使えて、何に使えないか。** 上記2つの限界のため、この章が計算する`T_r`・`ω_n`・`ζ`・立ち上がり時間は、**「自分の車が実際に何秒で向きを変えるか」の正確な予測値ではありません。** それでもこの章の数値には明確な使いみちがあります——**設計目標を数値で置くこと**（「今のセットアップより`ω_n`を上げたい／`ζ`を上げたい」という方向性を数字で語れるようにする）、そして**第37章（LQR）・第39章（MPC）が内部予測モデルとして使う`A`・`B`のサイジングの目安**です。制御器の設計は「モデルが正確である」ことを前提にするのではなく「モデルが持つ誤差の範囲でロバストに効く」ことを目指すため、この章の線形モデルの`ω_n`・`ζ`は、その設計の出発点として十分な価値を持ちます。**この章の計算結果を「限界域での挙動の予測」に使わないでください。** それは第3〜4章で繰り返し述べた限界（横加速度0.3〜0.4gを超えると前提が崩れる）が、この章にもそのまま引き継がれているからです。

**3. 臨界速度`V_cr`の誤読に、この章からも改めて注意します。** `ω_n²→0`となる`V_cr`は、開ループ（舵角固定）での話です。ドライバが閉ループで（ハンドルを操作しながら）安定化していれば、この章が「不安定」と計算する速度域でも実際には走れます（Guiggiani, 2026）。

## 学生チームでの現実解

1. **まず本章のMATLABコードの`p`を自チームの値に置き換え、`ω_n`・`ζ`・`T_r`を自分の車の実用速度域（例：5〜30 m/s）で計算する。** `ζ`が1を下回る速度（この章の例では`V*≈18 m/s`）が自分の実用速度域に入っているかどうかを確認してください。入っていれば、その先の速度でオーバーシュートが理論上存在することになります。
2. **ステップステア試験を計画する。** これは学生チームが実際に走らせられる標準的な検証マヌーバーです（第26章で手順を詳しく扱います）。測定するのは、最低限、**IMUのヨーレート`r(t)`**と**ステアリング角センサ（またはポテンショメータ）による舵角`δ(t)`**の時系列です。舵角がステップ状に変化した瞬間を基準に、この章と同じ手順（立ち上がり時間・ピーク・オーバーシュート・整定時間）で実測データを処理し、この章のMATLABコードが計算した値と比較してください。
3. **比較して合わなければ、まずこの章の限界を疑う。** 実測の応答時間がこの章の計算値より遅ければ、まず「限界と適用範囲」で述べたタイヤの緩和長（このモデルには入っていない）を疑ってください。実測でオーバーシュートの量がこの章の予測と大きく違えば、`K_f`・`K_r`・`I_z`の同定精度（第24〜25章）を疑ってください。
4. **`ω_n`・`ζ`を「セットアップの方向」を語る言葉として使う。** 「もっと機敏な車にしたい」なら`ω_n`を上げる方向（軽量化・`I_z`低減・タイヤのコーナリングスティフネス増）を、「もっと落ち着いた車にしたい」なら`ζ`を上げる方向を、それぞれこの章の式から定性的に読み取れます。ただし定量的な「何がどれだけ効くか」は、この線形モデルの中だけの話であることを忘れないでください。
5. **今すぐ試せる最初のステップ：** 本章のMATLABコードをそのまま実行し（環境が無ければ手計算・Excelでも構いません）、V=15 m/sとV=35 m/sの2つの速度でステップ応答を比較してください。オーバーシュートの有無だけでなく、**どちらが速く目標に到達するか**（立ち上がり時間・整定時間）を必ず両方確認し、「オーバーシュートする車が必ずしも速く動き出すわけではない」というこの章の結果を、自分の手で再現してください。
