## この章でできるようになること

- 接地点の速度ベクトルとタイヤの向きのずれから、**スリップ角**`α`をISO 8855の符号規約で定義できる。
- トレッド（タイヤ接地面のゴム）の変形という物理描像から、なぜスリップ角が横力を生むのかを説明できる。
- **コーナリングスティフネス**`C_α`を`α = 0`での傾きとして定義し、ISO 8855のもとで`F_y`と`α`が常に逆符号になることを正しく述べられる。
- 接地荷重`F_z`が増えると`C_α`も増えるが、比例よりゆっくり増える（劣線形）ことを理解し、これが荷重移動時のグリップ低下（第13章）にどうつながるかを説明できる。
- 線形タイヤモデルをMATLABで実装し、`α`に対する`F_y`のスイープと、`F_z`による`C_α`の変化を計算できる。

## なぜ必要か

第3章で組み立てる線形2自由度バイシクルモデルは、前後輪それぞれのタイヤが生む横力を、たった1つの数`C_α`（前軸用と後軸用の2つ）で表現します。タイヤという複雑な粘弾性体を1つの係数に圧縮できるのは、車両が実際に走る範囲の大半で、横力がスリップ角にほぼ比例するという事実があるからです。この章の役割は、その比例関係がどこから来るのか、そしてなぜ「タイヤは滑らないと力を出さない」のかを、次章でモデルを組む前に押さえておくことです。

ここで押さえる符号関係を取り違えると、影響は次章以降に静かに伝播します。`C_α`の符号や、`F_y`と`α`の符号の向きを逆にしたバイシクルモデルは、コンパイルもシミュレーションも問題なく通ります。ところがその模型は、本来なら直進姿勢に戻そうとする復元力が、逆にスリップを助長する方向に働くモデルになってしまい、定常円旋回はおろか直進走行でさえ発散します。第1章で座標系の符号を最初に固定したのと同じ理由で、この章でもタイヤ力の符号を最初に固定します。

なお、この章で組み立てるのはタイヤが横滑りだけをしている状態（純横滑り）の線形モデルに限ります。スリップ角が大きくなったときの非線形域や、制動しながら旋回するような複合スリップは、第8章（Magic Formula）・第10章（複合スリップ）で扱います。ここでは第3章が必要とする最小限、すなわち`α = 0`近傍の直線とその傾き`C_α`だけを扱います。

## 理論

### スリップ角の定義

タイヤの**スリップ角**`α`は、タイヤの向き（ホイール面、タイヤが転がろうとしている方向）と、接地点が実際に動いている方向とのずれの角度です。ホイール面に沿ってタイヤの前方を`x`、それに直交する横方向を`y`と取り、これを第1章のISO 8855（`x`前方・`y`左・`z`上向き）と同じ向きに揃えます（操舵角がついている場合は、タイヤ自身が向いている方向を基準に取ることに注意してください。車両全体の`x`・`y`との関係は、操舵角`δ`を介して次章で扱います）。

接地点の速度ベクトルを、この`x`・`y`方向に分解した成分を`v_x`・`v_y`とすると、スリップ角は

`tan α = v_y / v_x`

で定義できます。`v_x`は転がり方向の速度（走行中は基本的に正）、`v_y`はそれと直交する横方向の速度で、ISO 8855の`y`と同じく左向きが正です。したがって、接地点の速度が進行方向より左に振れているとき（`v_y > 0`）を`α > 0`とします。旋回中の小さいスリップ角の範囲では`tan α ≈ α`（ラジアン）とみなせるため、以下では`α`をラジアンで扱い、`α ≈ v_y / v_x`として近似します。

**符号の置き方は文献によって異なります。** 一部の文献は`α`の定義そのものにマイナス符号を組み込み（`tan α = −v_y/v_x`）、その代わりに`F_y = +C_α·α`と書きます。本書は上記のとおり`α`を符号なしで速度成分そのものから定義し、その結果として後述のとおり`F_y = −C_α·α`（`C_α > 0`）という形になる流儀を採用します。理由は単純で、`C_α`をカタログ値・データシートと同じ「正の量」として扱えるからです。どちらの流儀でも物理現象は同じですが、**式だけを他の文献からコピーしてくると符号が食い違う**ことがあるので、必ずその文献の`α`の定義を確認してください。

### なぜ滑ると力が出るのか（トレッド変形の物理描像）

タイヤが横力を出す仕組みは、直感的には「滑って摩擦力が出る」と誤解されがちですが、線形域（`α`が小さい範囲）で実際に起きているのはむしろ逆で、**トレッドは接地区間の大部分でほとんど滑っていません**。

接地パッチ（タイヤが路面に接している領域）の先端（リーディングエッジ）で路面に触れたトレッド要素は、摩擦によっていったん路面に貼り付き、接地パッチを抜けるまでほぼその位置に留まります。一方、タイヤの本体（ベルト・カーカス）は`α`だけ横を向いたまま前進を続けるため、路面に貼り付いたトレッド要素は、タイヤ本体から見ると横方向にじわじわ取り残されていきます。リーディングエッジからの距離を`x`とすると、この横方向のたわみ量`y_defl`は、小さい`α`の範囲でおおよそ

`y_defl(x) ≈ −α · x`

のように、リーディングエッジからの距離に比例して蓄積します（符号がマイナスなのは、`α`の向きと逆向きにタイヤ本体から取り残されるためです）。トレッドをばねの集合とみなし、単位長さあたりの横剛性を`k`とすると、位置`x`での局所的な力は`k · y_defl(x)`、接地パッチ全体の長さを`L`として積分すると

```text
F_y = ∫ k · y_defl(x) dx   (x: 0 → L)
    = ∫ k · (−α · x) dx
    = −(k·L² / 2) · α
```

となり、`F_y`が`α`に比例する線形関係と、それが負符号を持つことの両方が、トレッド変形の積分から導かれます。同時にこの式は、コーナリングスティフネスが接地パッチの長さ`L`（およびトレッド剛性`k`）に依存することも示しています。これは次の荷重依存性の話に直結します。

（この描像は接地パッチ全体が「貼り付いたまま」変形する線形域だけを説明するものです。`α`が大きくなり、パッチの後方から実際に滑り出す領域が生じると、力の伸びは頭打ちになります。この非線形域は第8章の対象です。）

### コーナリングスティフネスの定義

**コーナリングスティフネス**`C_α`は、`F_y`–`α`曲線の`α = 0`における傾きの大きさとして、

`C_α := −∂F_y/∂α |_{α=0}`　（`C_α > 0`）

と定義します（単位は[記号表](../../notation/)のとおりN/rad）。マイナス符号を明示的に含めているのは、前段で確認したとおり、生の傾き`∂F_y/∂α`自体は負だからです。この定義により、`α = 0`近傍の線形域では

`F_y = −C_α · α`

という関係が成り立ちます。**ISO 8855のもとでは、`F_y`と`α`は常に逆符号になります。** `α > 0`（接地点の速度が進行方向より左に振れている）なら`F_y < 0`（右向きの力）、`α < 0`なら`F_y > 0`（左向きの力）です。

この逆符号の関係は、単なる表記上の約束ではなく、タイヤが安定に働くための物理的な要請でもあります。もし符号を取り違えて`F_y = +C_α·α`（`C_α > 0`）という式をモデルに実装してしまうと、わずかなスリップ角がそのスリップをさらに助長する向きに力を発生させることになり、直進走行ですら発散する不安定なモデルになります。実装セクションのコードでは、この符号を明示的にコメントで示します。

### 荷重依存性（第13章への布石）

`C_α`は接地荷重`F_z`が増えるほど大きくなりますが、その増え方は`F_z`に比例するよりも緩やかです（劣線形）。前段のトレッド変形の描像に沿って言えば、`F_z`が増えると接地パッチは長く・広くなり`L`が増えるため`C_α`は増加しますが、実際のタイヤでは接地圧の分布やゴムの非線形性が変化するため、単純な`L²`の比例関係からは外れ、増加は徐々に頭打ちになります。

この性質が、レース車両の運動でなぜ重要かというと、コーナリング中の**横方向の荷重移動**（外輪に荷重が増え、内輪の荷重が減る現象）と組み合わさったときに効いてくるからです。`C_α`が`F_z`に対して劣線形（上に凸）である以上、外輪が得る`C_α`の増分は、内輪が失う`C_α`の減少分より小さくなります。その結果、荷重移動が起きた軸全体のコーナリングスティフネス（ひいては発生できる横力の総和）は、荷重移動がない場合より低下します。この効果を定量的に扱うのが第13章（荷重移動）です。ここでは「`C_α`は`F_z`に対して劣線形に増える」という事実だけを、次の実装セクションで数値的に確認します。

### 自己整列モーメントについて（一言だけ）

スリップ角がついたタイヤは、横力`F_y`だけでなく、接地パッチ内の圧力分布が前後非対称になることで、鉛直軸まわりのモーメント（**セルフアライニングトルク**）も発生します。これは`F_y`の作用点が幾何学的な接地点そのものではなく、進行方向にわずかにずれた位置（**ニューマチックトレイル**）にあることに相当します。このモーメントはステアリングの手応え（ステアリングフィール）を決める主要因であり、第19〜20章（操舵の運動学とフィードバック）で必要になります。第3章のバイシクルモデルでは扱わないため、本章でもこれ以上踏み込みません。

## 実装

以下のMATLABコードは、上で導いた線形タイヤモデル`F_y = −C_α·α`を使って、`α`を小角範囲で振ったときの`F_y`を計算し、さらに単純化したべき乗則`C_α(F_z) = C_α,ref·(F_z/F_z,ref)^p`（`p < 1`）を使って、接地荷重`F_z`を2倍にしたときに`C_α`が2倍未満にしか増えない（劣線形になる）ことを数値で確認します。base MATLABの機能（`deg2rad`・`fprintf`・無名関数・`plot`）のみを使用しており、追加のToolboxは不要です。

```matlab
% タイヤの線形域モデルとコーナリングスティフネスの荷重依存性
% ISO 8855: x 前方 / y 左 / z 上向き（第1章の座標系に準拠）
%
% スリップ角 alpha は、タイヤの向き（ホイール面、x_w 方向）から
% 接地点の速度ベクトルまでの角度とする。ISO 8855 の y は左が正なので、
% 速度ベクトルが進行方向より左に傾いているとき（v_y > 0）を alpha > 0 とする。
% トレッドは接地区間の入口でいったん路面に貼り付き、タイヤ本体が
% alpha だけ横に向きを変えて進んでもその場に取り残されるため、タイヤ本体
% から見た変位は alpha と逆向きに蓄積する。したがって生じる横力も alpha と
% 逆符号になり、
%   F_y = -C_alpha * alpha        （C_alpha > 0、線形域のみ）
% と書ける。C_alpha はカタログ値と同じく正の量として定義する。

clear; clc;

%% 1. 線形タイヤモデル: alpha を振って F_y を求める
C_alpha_nominal = 800 * (180/pi);   % 800 N/deg を N/rad に換算（目安値。実測ではない）

alpha_deg = -6:1:6;                 % スリップ角スイープ [deg]（線形域を想定した小角範囲）
alpha_rad = deg2rad(alpha_deg);

Fy = -C_alpha_nominal * alpha_rad;  % ISO 8855: alpha>0（左向きの滑り）で Fy<0（右向きの力）

fprintf('--- 線形タイヤモデル: alpha と F_y ---\n');
fprintf('C_alpha = %.1f N/rad (%.1f N/deg)\n\n', C_alpha_nominal, C_alpha_nominal*pi/180);
for k = 1:length(alpha_deg)
    fprintf('alpha = %+5.1f deg  ->  F_y = %+8.1f N\n', alpha_deg(k), Fy(k));
end

figure;
plot(alpha_deg, Fy, '-o');
xlabel('\alpha [deg]');
ylabel('F_y [N]');
title('線形タイヤモデル: F_y = -C_\alpha \cdot \alpha');
grid on;

%% 2. 荷重依存性: C_alpha は F_z とともに増えるが、比例よりゆっくり増える
% 単純化した経験則（べき乗則）: C_alpha(Fz) = C_alpha_ref * (Fz/Fz_ref)^p , p<1
% p<1 であれば、Fz を2倍にしても C_alpha は2倍未満にしかならない（劣線形）。
% ここでの数値は傾向を示すための仮の値であり、実測値ではない。
% 実際の値は第9章（タイヤフィッティング）・第24章（パラメータ取得）で
% 実測データから求める。

Fz_ref     = 1000;   % N（基準荷重）
Calpha_ref = 45000;  % N/rad（基準荷重での C_alpha の目安値）
p          = 0.8;    % べき指数（<1 で劣線形）

cornering_stiffness = @(Fz) Calpha_ref * (Fz / Fz_ref).^p;

Fz1 = 1000;   % N
Fz2 = 2000;   % N（Fz1 の2倍）

Ca1 = cornering_stiffness(Fz1);
Ca2 = cornering_stiffness(Fz2);
ratio_Fz = Fz2 / Fz1;
ratio_Ca = Ca2 / Ca1;

fprintf('\n--- 荷重依存性: F_z を2倍にしたときの C_alpha ---\n');
fprintf('F_z1 = %.0f N  ->  C_alpha1 = %.1f N/rad\n', Fz1, Ca1);
fprintf('F_z2 = %.0f N  ->  C_alpha2 = %.1f N/rad\n', Fz2, Ca2);
fprintf('F_z の倍率     = %.3f\n', ratio_Fz);
fprintf('C_alpha の倍率 = %.3f\n', ratio_Ca);
if ratio_Ca < ratio_Fz
    fprintf('-> F_z を2倍にしても C_alpha の増加は2倍未満（劣線形）。\n');
else
    fprintf('-> 想定外: 比例以上に増加している。p の値を確認すること。\n');
end
```

`C_alpha_nominal`と`Calpha_ref`はどちらも実測値ではなく、学生フォーミュラ規模のタイヤでオーダーが合うように置いた仮の値です。荷重依存性のべき指数`p = 0.8`も、劣線形の傾向を示すための単純化であり、実際のタイヤの`C_α(F_z)`カーブは滑らかな山なりの後に頭打ちになるなど、べき乗則よりも複雑な形を取ります。自分のチームのタイヤで実際の値を使う場合は、この仮の値をそのまま使わず、第9章・第24章の手順で測定・同定した値に置き換えてください。

## 限界と適用範囲

本章の線形タイヤモデルには、次のような限界があります。

**1. 線形域（小さい`α`）に限られる。** `α`が大きくなり接地パッチの後方から実際の滑りが始まると、`F_y`の伸びは頭打ちになり、やがてピークを迎えて減少します。この全域を表すのが第8章のMagic Formulaです。本章の`F_y = −C_α·α`は、あくまでその曲線の原点付近の接線にすぎません。

**2. 純横滑りのみを扱う。** 制動・駆動しながら旋回するような、前後力と横力が同時に発生する状況（複合スリップ）は扱っていません。複合スリップ下では、同じ`α`でも横力は本章の値より小さくなります（第10章）。

**3. `C_α`の荷重依存性以外の依存性を無視している。** 実際の`C_α`は、接地荷重だけでなく、内圧・温度・キャンバー角によっても変化します。温度・荷重の依存性は第11章で扱います。

**4. セルフアライニングモーメントを扱っていない。** 前述のとおり、ステアリングフィールに関わるモーメントは第19〜20章の対象です。

**5. 本章の数値は実測ではない。** 実装セクションで使った`C_alpha_nominal`・`Calpha_ref`・`p`はいずれも傾向を示すための仮の値です。自分のタイヤの実際の`C_α`は、第9章（タイヤフィッティング）・第24章（パラメータ取得）の手順で、実測データから求めてください。

## 学生チームでの現実解

学生フォーミュラのチームが、自分たちの車両モデルに使う`C_α`を用意するときの現実的な進め方は次の通りです。

1. **タイヤメーカーの実測データが手に入るか確認する。** FSAE界隈で広く使われているタイヤ（Hoosier・Continentalなど）については、Tire Test Consortium（TTC）がCalspan社のタイヤ試験機で取得した実測データを、参加チームに提供しています。自チームまたは他チームがTTCデータへのアクセスを持っている場合、それが最も信頼できる`C_α`の出発点になります。
2. **実測データがすぐに手に入らない場合は、仮の値で車両モデルの骨組みを先に組む。** 本章のコードのように「オーダーが合っている仮の値」を置き、第3章のバイシクルモデルやそれ以降の解析コードを先に動かせる状態にしておきます。ただし、その値が仮置きであることをコードのコメントとチームのWikiに明記し、後から実測値に差し替える作業を忘れないようにします。
3. **スキッドパッド試験から間接的に推定する。** 一定半径の定常円旋回試験（第26章で扱う検証マニューバの1つ）を行い、そのときの横加速度・車速・舵角から、前後軸それぞれの実効的な`C_α`を逆算する方法があります。ただし、この方法で得られるのはタイヤ単体ではなく「車両に組み付いた状態の軸全体」の値であり、サスペンションのコンプライアンスなど他の要因も混ざります。位置づけの違いを理解した上で使ってください（詳細は第24・26章）。
4. **前後軸の`C_α`を、タイヤ1本の値の単純な定数倍にしない。** 前軸2輪・後軸2輪それぞれの荷重は、静止時の荷重配分に加えて、コーナリング中の横方向の荷重移動でも変化します。本章で確認したとおり`C_α(F_z)`は劣線形なので、「1本の`C_α`を2倍する」だけでは軸全体の`C_α`を過大評価します。正しい積み上げ方は第13章で扱います。
5. **今すぐ試せる最初のステップ：** 本章のMATLABコードをそのまま実行し、`alpha_deg`の範囲や`p`の値を変えながら、`F_y`の傾きと`C_α`の変化がどう動くかを手を動かして確認してください。次章のバイシクルモデルに入る前に、この2つの感覚（`F_y`と`α`の逆符号・`C_α`の劣線形な荷重依存性）を持っておくと、モデルの結果が物理的に妥当かどうかを自分で判断できるようになります。

## 次の章へ

この章で固定した`F_y = −C_α·α`という関係を、次章（第3章「線形2自由度バイシクルモデル」）では前軸・後軸それぞれのタイヤに当てはめ、車両質量`m`・ヨー慣性`I_z`・重心位置（`l_f`・`l_r`）・前輪舵角`δ`と組み合わせて、車両全体の運動方程式を組み立てます。そこでは本章のように接地点の速度成分から直接`α`を求めるのではなく、車体すべり角`β`・ヨーレート`r`・車速`V`・舵角`δ`といった車両レベルの量から、前後軸の`α`を導出する形に一般化します。
