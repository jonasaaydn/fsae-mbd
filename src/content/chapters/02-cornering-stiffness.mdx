## この章でできるようになること

- 接地点の速度ベクトルとタイヤの向きのずれから、**スリップ角**`α`をISO 8855の符号規約で定義できる。
- **軸あたりのコーナリングスティフネス**`K_f`・`K_r`と**1輪あたり**`C_α`を区別し、`K = 2·C_α`という関係と、単位系（rad系とdeg系で57.3倍ずれること）を説明できる。
- トレッド（タイヤ接地面のゴム）の変形という物理描像から、なぜスリップ角が横力を生むのかを説明できる。
- `Fy = -C_α·α`という線形タイヤモデルが依拠する6つの仮定を列挙し、それぞれがいつ破綻するかを言える。
- **ブラシモデル**を使って`C_α`を接地パッチ半長`a`・トレッド剛性`cp`・摩擦係数`μ`から導出でき、`C_α = 2·cp·a²`という関係と、横力が`μ·Fz`で頭打ちになることを両方説明できる。
- 接地荷重`F_z`が増えると`C_α`も増えるが比例よりゆっくり増える（劣線形）理由を、ブラシモデルの物理から説明し、これが荷重移動時のグリップ低下（第13章）にどうつながるかを言える。
- タイヤ力がスリップ入力に瞬時には追従しないこと（過渡遅れ）と、それが時間ではなく走行距離で決まることを知っている。
- 自チームが`C_α`を実際にどう入手するか（TTC・スキッドパッド逆算・接地痕実測・既定値からの差し替え）を、優先順位付きで選べる。
- 線形タイヤモデルとブラシモデルの両方をMATLABで実装し、単体テストで符号と荷重依存性を検証できる。

## なぜ必要か

この章が答える問いは1つです。**「`Fy = -C_α·α`の`C_α`とは何か。どこから来て、いつ使えなくなるのか」**。

前章では車両座標系の符号を固定しました。第3章で組み立てる線形2自由度バイシクルモデルは、前後輪それぞれのタイヤが生む横力を、たった1つの数`C_α`（前軸用と後軸用の2つ）で表現します。タイヤという複雑な粘弾性体を1つの係数に圧縮できるのは、車両が実際に走る範囲の大半で、横力がスリップ角にほぼ比例するという事実があるからです。

ここで`C_α`を「タイヤのカタログ値」や「TTCデータに当てはめて出てくる数」としてだけ扱うと、あとの章がすべて暗記になります。`C_α`が接地長・トレッド剛性・摩擦から出る数だと知っていれば、第10章の摩擦円（横力と前後力は同時に最大にできない）も、第13章の荷重感度（ロール剛性配分がなぜアンダー・オーバーを決めるか）も、第20章のトレール減少（限界付近でステアリングの手応えが抜ける理由）も、すべて同じ1つの物理描像の帰結として理解できます。逆にここを素通りすると、それらの章は「そういうものだ」という個別の暗記になり、初めて見るタイヤやセットアップに応用が利きません。

とりわけ荷重依存性は本書全体の要です。第13章の中心的な主張——ロール剛性配分を前寄りにすると、前軸の横荷重移動が増え、荷重感度によって前軸のトータルグリップが下がり、結果としてアンダーステアになる——は、`C_α(F_z)`と`μ(F_z)`が荷重とともに頭打ちになるという事実の上に完全に建っています。この章で荷重依存性を扱わなければ、その因果連鎖の出発点が本書のどこにも存在しないことになります。

なお、この章で組み立てるのはタイヤが横滑りだけをしている状態（純横滑り）の線形〜準線形モデルに限ります。スリップ角が大きくなったときの厳密な非線形域や、制動しながら旋回するような複合スリップは、第8章（Magic Formula）・第10章（複合スリップ）で扱います。ここでは第3章が必要とする最小限、すなわち`α = 0`近傍の傾き`C_α`と、その傾きがどこから来てどこで通用しなくなるかだけを扱います。

## 理論

### スリップ角の定義

タイヤの**スリップ角**`α`は、タイヤの向き（ホイール面、タイヤが転がろうとしている方向）と、接地点が実際に動いている方向とのずれの角度です。ホイール面に沿ってタイヤの前方を`x`、それに直交する横方向を`y`と取り、これを第1章のISO 8855（`x`前方・`y`左・`z`上向き）と同じ向きに揃えます（操舵角がついている場合は、タイヤ自身が向いている方向を基準に取ることに注意してください。車両全体の`x`・`y`との関係は、操舵角`δ`を介して次章で扱います）。

接地点の速度ベクトルを、この`x`・`y`方向に分解した成分を`v_x`・`v_y`とすると、スリップ角は

`tan α = v_y / v_x`

で定義できます。`v_x`は転がり方向の速度（走行中は基本的に正）、`v_y`はそれと直交する横方向の速度で、ISO 8855の`y`と同じく左向きが正です。したがって、接地点の速度が進行方向より左に振れているとき（`v_y > 0`）を`α > 0`とします。旋回中の小さいスリップ角の範囲では`tan α ≈ α`（ラジアン）とみなせるため、以下では`α`をラジアンで扱い、`α ≈ v_y / v_x`として近似します。

**符号の置き方は文献によって異なります。** 一部の文献は`α`の定義そのものにマイナス符号を組み込み（`tan α = −v_y/v_x`）、その代わりに`F_y = +C_α·α`と書きます。本書は上記のとおり`α`を符号なしで速度成分そのものから定義し、その結果として後述のとおり`F_y = −C_α·α`（`C_α > 0`）という形になる流儀を採用します。理由は単純で、`C_α`をカタログ値・データシートと同じ「正の量」として扱えるからです。どちらの流儀でも物理現象は同じですが、**式だけを他の文献からコピーしてくると符号が食い違う**ことがあるので、必ずその文献の`α`の定義を確認してください。

### 符号規約の宣言：軸あたりと1輪あたり、そして単位（本書で1度だけ）

先へ進む前に、本書全体で使う3つの約束をここで1度だけ固定します。以降の章はこの約束を前提にするので、混在させないでください。

**1. 軸あたりと1輪あたりを区別する。** 第3章のバイシクルモデルが必要とするのは、前軸・後軸それぞれの**軸あたりのコーナリングスティフネス**`K_f`・`K_r`です。一方、この章で導出する`C_α`は**1輪あたり**の量です。左右の輪が同じ荷重・同じ`α`を持つと仮定できる範囲では、軸は2輪の並列なので

`K = 2 · C_α`

という関係になります。安部（Abe, *Vehicle Handling Dynamics*, 2nd ed., 2015）をはじめ、バイシクルモデルの運動方程式に係数「2」が現れる文献の多くは、この「1輪あたりの`C_α`を軸あたりに束ねる」操作に由来する2です。第13章以降、コーナリング中の荷重移動で左右輪の荷重が等しくなくなると、単純な2倍では済まなくなります（`C_α(F_z)`が劣線形だからです。後述）。この章のMATLAB実装は1輪あたりの`C_α`を扱い、軸あたりへの正しい積み上げ方は第13章で扱います。

**2. 単位はラジアン系で統一する。** 本書は`C_α`を常に`N/rad`で扱います。文献によっては`N/deg`や、車両運動の文脈でよく見る`deg/g`（横加速度1gあたり何度のスリップ角が付くか、という感度の単位）で書かれていることがあります。Gillespieの教科書はdeg/g系の単位を使うことで知られています。rad系とdeg系は

`1 rad = 180/π deg ≈ 57.3 deg`

の関係にあるため、deg系で書かれた`C_α`をそのままrad系の式に代入すると、**約57.3倍**の誤差になります。この換算を忘れることは、本プロジェクトで実際に3度発生した符号・単位の取り違えと同じ種類の事故です。文献の数値を使うときは、その文献がどちらの単位系かを必ず確認し、章をまたいで単位を混在させないでください。

### なぜ滑ると力が出るのか（トレッド変形の物理描像）

タイヤが横力を出す仕組みは、直感的には「滑って摩擦力が出る」と誤解されがちですが、線形域（`α`が小さい範囲）で実際に起きているのはむしろ逆で、**トレッドは接地区間の大部分でほとんど滑っていません**。

接地パッチ（タイヤが路面に接している領域）の先端（リーディングエッジ）で路面に触れたトレッド要素は、摩擦によっていったん路面に貼り付き、接地パッチを抜けるまでほぼその位置に留まります。一方、タイヤの本体（ベルト・カーカス）は`α`だけ横を向いたまま前進を続けるため、路面に貼り付いたトレッド要素は、タイヤ本体から見ると横方向にじわじわ取り残されていきます。

以下、接地パッチの全長を`2a`（`a`を接地パッチの半長）と表記します。ブラシモデルの文献でよく使われる記法に合わせるためで、**この章に限り`a`は加速度`a_x`・`a_y`ではなく接地パッチの半長を指す**ことに注意してください。リーディングエッジからの距離を`ξ`（`0 ≤ ξ ≤ 2a`）とすると、この横方向のたわみ量`y(ξ)`は、小さい`α`の範囲でおおよそ

`y(ξ) ≈ α · ξ`

のように、リーディングエッジからの距離に比例して蓄積します。トレッドをばねの集合とみなし、単位長さあたりの横剛性を`cp`とすると、位置`ξ`での局所的な力（単位長さあたり）は`cp · y(ξ)`、接地パッチ全体で積分すると

```text
Fy = -∫ cp · y(ξ) dξ   (ξ: 0 → 2a)
   = -∫ cp · α · ξ dξ
   = -cp · α · [ξ²/2]  (0 → 2a)
   = -2·cp·a² · α
```

となり、`Fy`が`α`に比例する線形関係が、トレッド変形の積分から導かれます（負号は、たわみが`α`と逆向きに蓄積し、それを戻そうとする力がISO 8855の符号で`α`と逆符号になることに対応します。前段の`F_y = -C_α·α`と整合しています）。この結果は次の節でそのまま`C_α = 2·cp·a²`として回収されます。

**ただしこの積分には、まだ触れていない前提があります。** `y(ξ) ≈ α·ξ`という直線的な蓄積は、トレッド要素が接地パッチの出口まで**ずっと貼り付いたまま**である場合にしか成り立ちません。しかし局所的な力`cp·y(ξ)`は`ξ`とともに際限なく増え続けることはできません。路面とゴムの間の摩擦には限界があるからです。この限界を明示的に扱うのが次節のブラシモデルです。

### C_αはどこから来るのか：ブラシモデルによる導出

前節の積分は、`α`が十分小さく、接地パッチ全体が貼り付いたままでいられる範囲でだけ正しい近似でした。ここでは摩擦の限界を明示的に組み込み、`C_α`が**どこから来る数か**を導出します。

**モデルの仮定：**
- タイヤの接地圧`q_z(ξ)`は、接地パッチの中心で最大、両端でゼロになる放物線分布とする。
- 路面とトレッドの摩擦係数`μ`は接地パッチ全体で一定とする。
- カーカス（タイヤのベルト・骨格部分）は剛体とみなし、変形するのはトレッドゴムだけとする。
- 定常状態（`α`が時間変化しない）を扱う。過渡的な遅れは第7章。

接地荷重`F_z`を放物線分布として積分が`F_z`に一致するように書くと、

```text
qz(ξ) = (3·Fz)/(4a) · [1 - ((ξ-a)/a)²]     (0 ≤ ξ ≤ 2a)
```

となります（中心`ξ = a`で最大値`3Fz/4a`、両端`ξ = 0, 2a`でゼロ）。実際に`∫₀^{2a} qz(ξ) dξ = Fz`となることは、置換積分で確認できます。

**粘着域（リーディングエッジ側）。** トレッド要素が路面に貼り付いたままでいられるのは、必要な局所横力`cp·α·ξ`が、その位置で出せる最大摩擦力`μ·qz(ξ)`を超えない間だけです。`ξ`が小さいリーディングエッジ付近では`qz(ξ)`（放物線の立ち上がり）の方が`cp·α·ξ`（原点からの直線）より大きいため、この領域は粘着域になります。

**すべり域（トレーリングエッジ側）。** `ξ`が大きくなるにつれて必要な横力`cp·α·ξ`は直線的に増え続けますが、接地圧`qz(ξ)`は放物線の後半でむしろ減少していきます。したがってどこかで`cp·α·ξ`が`μ·qz(ξ)`を超え、その位置から先のトレッド要素は路面に対して実際に滑り始めます。滑っている要素が出せる力は、もはやトレッド剛性`cp`ではなく、そのときの接地圧で決まる動摩擦力`μ·qz(ξ)`そのものに切り替わります。トレーリングエッジに近づくほど`qz(ξ) → 0`なので、すべり域の力も先細りになります。

<BrushModel />

**原点での傾き（粘着域だけの積分）。** `α → 0`の極限では、すべり域が生じる前に、粘着域だけの積分がそのまま`Fy`を与えます。これは前節で行った積分そのもので、

```text
Cα := -∂Fy/∂α |_{α=0} = 2·cp·a²
```

という関係が、ブラシモデルの解析解として直接得られます。**つまり`C_α`は測定して初めて分かる謎の数ではなく、接地パッチの半長`a`・トレッド単位長さあたりの剛性`cp`から計算できる数です。** `a`が大きい（接地パッチが長い）タイヤほど、`cp`が大きい（トレッドが硬い）タイヤほど`C_α`は大きくなります。

**飽和（`α`が大きい極限）。** `α`が十分大きくなると、粘着域はリーディングエッジ付近のごく一部にまで縮み、接地パッチのほぼ全体がすべり域になります。この極限では局所力がすべて`μ·qz(ξ)`で決まるため、

```text
Fy,max = ∫ μ·qz(ξ) dξ (0→2a) = μ·Fz
```

となります。**これが線形モデルには存在しなかった上限です。** `Fy = -C_α·α`は`α`とともに際限なく大きくなりますが、実際のタイヤは`μ·Fz`で頭打ちになります。

**両極限をつなぐ閉じた形。** 粘着域とすべり域それぞれの積分を、両者の境界位置`ξ_s`（`cp·α·ξ_s = μ·qz(ξ_s)`を満たす点）で貼り合わせて解くと（境界条件の代数操作は付録的なので結果だけ示します）、無次元スリップ量

`θ := C_α·|α| / (3·μ·Fz)`

を使って

```text
           μ·Fz · [1 − (1 − θ)³]   (0 ≤ θ ≤ 1 のとき)
|Fy(α)| =
           μ·Fz                   (θ ≥ 1 のとき、全面すべり)
```

という閉じた形が得られます（符号は`sign(α)`を掛けて`ISO`規約に合わせます）。この式が2つの極限を正しく含んでいることは、境界値で確認できます。`θ → 0`（`α → 0`）でテイラー展開すると`|Fy| ≈ 3μFz·θ = C_α·|α|`となり原点の傾きが一致し、`θ = 1`では`|Fy| = μFz`で飽和値と一致します。同じ被積分関数からモーメント`ξ - a`を掛けて積分すると、ニューマチックトレイル`t`（`Mz = -t·Fy`を満たす量）についても閉じた形が求まり、`α → 0`で`t → a/3`から出発し、`θ`とともに単調に減少して`θ = 1`（全面すべり、接地圧分布が対称になる）で`t = 0`に至ることが分かります。これは実装セクションのMATLABコードで数値的に確認します。

まとめると、ブラシモデルは1つの積分から3つの結果を同時に与えます。**`C_α = 2·cp·a²`（原点の傾き）、`Fy,max = μ·Fz`（線形モデルには無い摩擦飽和）、そして`t`が`a/3`から単調に減ってピーク付近でゼロに至ること（ステアリングフィールの手応え抜けの起源、第20章）。`C_α`は測る数ではなく、接地長・トレッド剛性・摩擦から出る数である、というのがこの節の結論です。**

### 荷重依存性 — tire load sensitivity（第13章への布石）

前節の`C_α = 2·cp·a²`と`Fy,max = μ·Fz`は、いずれも`F_z`が一定であるという仮定の下で導いた結果でした。ここではその仮定だけを外します。

実際のタイヤでは、接地荷重`F_z`が増えると接地パッチの面積はほぼ荷重に比例して増えます（インフレーション圧が一定なら、接地圧×面積 ≈ 荷重、という単純な釣り合いに近いためです）。面積が増えるということは、ブラシモデルの`a`（接地パッチ半長）も増えるということなので、`C_α = 2·cp·a²`はそのままでは荷重とともに増加します。

ところが、面積が増えると同時に**平均接地圧も上昇**します。ゴムの摩擦係数は、接地圧が上がるほど頭打ちになる（劣化する）性質を持つため、`μ`は荷重とともにゆっくり低下します。この効果が`a`の増加による`C_α`の増加を部分的に打ち消し、結果として`C_α`も`Fy,max = μ·Fz`も、荷重に比例するよりゆっくり増える（劣線形）挙動になります。おおよその目安として、`Fy`は`Fz`の0.7〜0.9乗程度の依存性を示すことが知られています。

この劣線形性は、レース車両の運動でなぜ重要かというと、コーナリング中の**横方向の荷重移動**（外輪に荷重が増え、内輪の荷重が減る現象）と組み合わさったときに効いてくるからです。`C_α`が`F_z`に対して劣線形（上に凸）である以上、外輪が得る`C_α`の増分は、内輪が失う`C_α`の減少分より小さくなります。その結果、荷重移動が起きた軸全体のコーナリングスティフネス（ひいては発生できる横力の総和）は、荷重移動がない場合より低下します。この効果を定量的に扱うのが第13章（荷重移動とロール剛性配分）です。

**荷重感度を無視することの影響がどれくらいの大きさかを、次の仮想的な例で確認します（実測ではなく、傾向を示すための仮定です）。** 半径`r = 8.5 m`のスキッドパッドを、摩擦係数`μ = 1.6`一定とみなして解くと、限界速度は

`v = √(μ·g·r) = √(1.6 × 9.81 × 8.5) ≈ 11.55 m/s ≈ 41.6 km/h`

です。ところが荷重移動と荷重感度（`C_α(F_z)`・`μ(F_z)`の劣線形性）を組み込んだモデルでは、内外輪の`μ`の非対称性により実効的な限界速度は約`37 km/h`にとどまります。これは**約12%の過大評価**に相当します。`μ`を定数として扱うと、このオーダーで系統的に楽観的な結果が出るということです。

実装上は、`C_α(F_z)`の関数形を解析式で仮定するのではなく、離散的な荷重点での値を持つ**テーブル**として扱い、`MATLAB`の`griddedInterpolant`で補間します。**外挿は必ず`'nearest'`（最近傍）でクランプします。** 多項式外挿を許すと、テーブル範囲外で`C_α`が負になったり非物理的に暴走したりする恐れがあるためです。この配慮は理論上の潔癖症ではありません。**FSAE車両は旋回中に内輪の荷重がほぼゼロまで抜けることが珍しくなく、低荷重側の外挿は実際に踏む領域だからです。** 具体的な実装は実装セクションで示します。

### 過渡の予告（定義は第7章）

ここまでの`C_α`は、スリップ角`α`が変化しても横力`F_y`が瞬時に追従するという、暗黙の**定常**仮定の上に成り立っています。実際のタイヤはそうではありません。`α`がステップ状に変化しても、`F_y`はある時定数を持って遅れながら追従します。

この時定数はおおよそ`σ/V`（`σ`は緩和長と呼ばれる長さの次元を持つ量、`V`は車速）で決まることが知られており、**時間ではなく走行距離で決まる**という性質を持ちます。これは直感に反する帰結を生みます。FSAEのような低速域（市街地程度の速度帯）を走る車両は、高速で走る乗用車に比べて同じ距離を進むのに時間がかかるため、**時間として測った遅れはむしろ長くなります**。「タイヤが小さいから過渡応答は速いはずだ」という直感は誤りです。緩和長の定義とMATLAB実装は第7章、この遅れが車両全体のヨーレート応答にどう効くかは第5章で扱います。ここでは「`F_y`は`α`に瞬時に追従しない」という事実だけを覚えておいてください。

### 自己整列モーメントについて

前節のブラシモデル導出で、ニューマチックトレイル`t`が`α → 0`で`a/3`から出発し、`α`とともに単調に減少してピーク付近でゼロに至ることを見ました。この`t`は、横力`F_y`の作用点が幾何学的な接地点そのものではなく、進行方向にわずかにずれた位置にあることに相当し、`Mz = -t·F_y`という関係でタイヤが路面から受けるモーメント（**セルフアライニングトルク**）を決めます。このモーメントはステアリングの手応え（ステアリングフィール）を決める主要因であり、第19〜20章（操舵の運動学とフィードバック）で必要になります。第3章のバイシクルモデルでは`Mz`を扱わないため、本章でもこれ以上は踏み込みません。

## 実装

以下のMATLABコードは、次の3つを実装します。base MATLABの機能（`deg2rad`・`rad2deg`・`fprintf`・`griddedInterpolant`・`plot`・ローカル関数）のみを使用しており、追加のToolboxは不要です。

1. `tyre_linear` — 線形タイヤモデル`Fy = -Cα·α`（第2.3節相当）
2. `tyre_brush` — ブラシモデルの解析解（第2.4節で導出した閉じた形）。`Fy`・`Mz`・トレイル`t`を返す
3. 荷重依存`Cα(Fz)`の`griddedInterpolant`（`'nearest'`外挿クランプ、第2.5節）

続けて、原点勾配が理論値`2·cp·a²`と一致すること、正の`α`で復元方向の`Mz`が出ること、`Fz`を2倍にしても`Cα`は2倍未満にしかならないこと、そして低荷重側の外挿がクランプされることを、単体テストとして`assert`で確認します。`tyre_linear`・`tyre_brush`は実プロジェクトでは別ファイル（`tyre_linear.m`・`tyre_brush.m`）に分け、第3章以降から再利用しますが、本章単体で実行できるよう、ここではスクリプト末尾のローカル関数としてまとめています。

```matlab
% タイヤ横力モデル：線形モデル・ブラシモデル（解析解）・荷重依存 Cα(Fz)
% ISO 8855: x 前方 / y 左 / z 上向き（第1章の座標系に準拠）
%
% alpha はタイヤの向き（ホイール面）から接地点の速度ベクトルまでの角度。
% ISO 8855 の y は左が正なので、速度ベクトルが進行方向より左に傾いているとき
% (v_y > 0) を alpha > 0 とする。第2.3節の約束のとおり、線形域では
%   Fy = -Calpha * alpha        (Calpha > 0)
% となる。tyre_brush はこれを摩擦飽和まで含めて一般化した解析解を返す。

clear; clc;

%% 1. tyre_linear: 線形タイヤモデル（第2.3節）
% Calpha は 1 輪あたりの正の値[N/rad]。900 N/deg を N/rad に換算した仮の値
% （実測ではない。実際の値は第9章・第24章でTTCデータ等から同定する）。
Calpha_nominal = 900 * (180/pi);

alpha_deg = -8:1:8;
alpha_rad = deg2rad(alpha_deg);
Fy_linear = tyre_linear(alpha_rad, Calpha_nominal);

fprintf('--- tyre_linear: 線形モデル ---\n');
fprintf('Calpha = %.1f N/rad (%.1f N/deg)\n\n', Calpha_nominal, Calpha_nominal*pi/180);
for k = 1:numel(alpha_deg)
    fprintf('alpha = %+5.1f deg  ->  Fy = %+8.1f N\n', alpha_deg(k), Fy_linear(k));
end

%% 2. tyre_brush: ブラシモデルの解析解（第2.4節）
% 仮のブラシパラメータ（実測ではない。オーダーが合う程度の仮定値。
% cp はトレッド単位長さあたりの横剛性、a は接地パッチ半長で、
% 加速度 a_x・a_y とは無関係）。
cp  = 4.0e6;    % トレッド剛性 [N/m^2]
a   = 0.05;     % 接地パッチ半長 [m]
mu  = 1.5;      % 摩擦係数（仮定）
Fz0 = 1000;     % 接地荷重 [N]（仮定）

Calpha_brush_theory = 2 * cp * a^2;
fprintf('\n--- tyre_brush: 原点勾配の理論値 ---\n');
fprintf('Calpha = 2*cp*a^2 = %.1f N/rad\n', Calpha_brush_theory);

alpha_sweep_deg = -25:0.5:25;
alpha_sweep_rad = deg2rad(alpha_sweep_deg);
n = numel(alpha_sweep_rad);
Fy_brush = zeros(1, n);
Mz_brush = zeros(1, n);
t_brush  = zeros(1, n);
for k = 1:n
    [Fy_brush(k), Mz_brush(k), t_brush(k)] = tyre_brush(alpha_sweep_rad(k), cp, a, mu, Fz0);
end

figure;
subplot(2,1,1);
plot(alpha_sweep_deg, Fy_brush, '-'); hold on;
plot(alpha_sweep_deg, -Calpha_brush_theory*alpha_sweep_rad, '--');
yline(-mu*Fz0, ':'); yline(mu*Fz0, ':');
xlabel('\alpha [deg]'); ylabel('F_y [N]');
legend('ブラシモデル(解析解)', '原点の接線(線形モデル)', 'Location', 'best');
title('ブラシモデル: F_y(\alpha) と原点での線形近似・摩擦飽和');
grid on;

subplot(2,1,2);
plot(alpha_sweep_deg, t_brush*1000, '-');
xlabel('\alpha [deg]'); ylabel('ニューマチックトレイル t [mm]');
title('トレイル t の \alpha に対する変化（a/3 から単調減少）');
grid on;

%% 3. 単体テスト1: 原点勾配が理論値と一致するか（数値微分で確認）
d_alpha = 1e-6;
[Fy_plus,  ~, ~] = tyre_brush(d_alpha,  cp, a, mu, Fz0);
[Fy_minus, ~, ~] = tyre_brush(-d_alpha, cp, a, mu, Fz0);
Calpha_numeric = -(Fy_plus - Fy_minus) / (2*d_alpha);

fprintf('\n--- 単体テスト1: 原点勾配 ---\n');
fprintf('理論値 (2*cp*a^2)    = %.3f N/rad\n', Calpha_brush_theory);
fprintf('数値微分による推定値  = %.3f N/rad\n', Calpha_numeric);
assert(abs(Calpha_numeric - Calpha_brush_theory) / Calpha_brush_theory < 1e-3, ...
    '原点勾配が理論値と一致しません');
fprintf('-> 一致（相対誤差 1e-3 未満）。\n');

%% 4. 単体テスト2: 正のalphaで復元方向のMzが出るか
alpha_test = deg2rad(3);
[Fy_test, Mz_test, t_test] = tyre_brush(alpha_test, cp, a, mu, Fz0);
fprintf('\n--- 単体テスト2: 復元方向のMz ---\n');
fprintf('alpha = %.1f deg -> Fy = %.1f N, Mz = %.4f N*m, t = %.2f mm\n', ...
    rad2deg(alpha_test), Fy_test, Mz_test, t_test*1000);
assert(Mz_test > 0, 'alpha>0 でMzが復元方向(正)になっていません');
fprintf('-> alpha>0 で Mz>0（車両を直進方向へ戻す向き）。復元方向を確認。\n');

%% 5. 荷重依存 Cα(Fz): griddedInterpolant + nearest外挿クランプ（第2.5節）
% 以下は劣線形の傾向を示すための仮のテーブルであり実測ではない。
% 実際の値は第9章・第24章でTTCデータ等から同定する。
Fz_table     = [300, 600, 1000, 1500, 2000, 2500];         % N
Calpha_table = [7600, 13300, 20000, 27700, 34800, 41600];  % N/rad

Ca_interp = griddedInterpolant(Fz_table, Calpha_table, 'linear', 'nearest');

fprintf('\n--- 単体テスト3: Fzを2倍にしてもCaは2倍未満 ---\n');
Fz1 = 1000; Fz2 = 2000;
Ca1 = Ca_interp(Fz1); Ca2 = Ca_interp(Fz2);
fprintf('Ca(%d N) = %.0f N/rad\n', Fz1, Ca1);
fprintf('Ca(%d N) = %.0f N/rad\n', Fz2, Ca2);
fprintf('Fzの倍率 = %.3f, Caの倍率 = %.3f\n', Fz2/Fz1, Ca2/Ca1);
assert(Ca2/Ca1 < Fz2/Fz1, 'Fzを2倍にしてもCaが2倍未満になっていません');
fprintf('-> 劣線形を確認。\n');

fprintf('\n--- 単体テスト4: 低荷重側の外挿クランプ（内輪 Fz->0 を想定） ---\n');
Fz_unloaded = 0;   % コーナリング中に内輪がほぼ抜けた状態を想定
Ca_unloaded = Ca_interp(Fz_unloaded);
fprintf('Ca(Fz=%d N) = %.0f N/rad （テーブル下端 Fz=%d N の値にクランプ）\n', ...
    Fz_unloaded, Ca_unloaded, Fz_table(1));
assert(Ca_unloaded == Calpha_table(1), 'Fz=0 でのクランプがテーブル下端値と一致しません');
fprintf('-> nearestクランプにより、テーブル外(Fz=0)でも多項式外挿による負値や暴走が発生しない。\n');

%% ローカル関数 -----------------------------------------------------
% 実プロジェクトでは tyre_linear.m / tyre_brush.m として分割し、
% 第3章以降のバイシクルモデル・第23章の統合モデルから再利用する。

function Fy = tyre_linear(alpha, Calpha)
% 線形タイヤモデル（第2.3節）。Calpha は1輪あたりの正の値[N/rad]。
% ISO 8855: alpha>0 (v_y>0) で Fy<0 となるよう符号を付ける。
    Fy = -Calpha .* alpha;
end

function [Fy, Mz, t] = tyre_brush(alpha, cp, a, mu, Fz)
% ブラシモデルの解析解（第2.4節の導出結果）。
% 入力: alpha [rad], cp トレッド剛性[N/m^2], a 接地パッチ半長[m],
%       mu 摩擦係数, Fz 接地荷重[N]
% 出力: Fy [N]（ISO 8855, alpha>0でFy<0）,
%       Mz [N*m]（alpha>0で正=復元方向）,
%       t  [m] ニューマチックトレイル（常に0以上、a/3から単調減少）
    Calpha = 2 * cp * a^2;                        % 原点勾配（=線形モデルのCalphaそのもの）
    theta  = Calpha * abs(alpha) / (3 * mu * Fz);
    theta_clamped = min(theta, 1);                % 全面すべり以降は飽和

    Fy_mag = mu * Fz * (1 - (1 - theta_clamped)^3);
    Fy = -sign(alpha) * Fy_mag;                   % ISO符号。alpha=0ではFy=0

    if theta_clamped < 1e-9
        t = a / 3;                                % alpha->0 の解析的極限
    elseif theta_clamped < 1
        denom = 1 - (1 - theta_clamped)^3;
        t = a * theta_clamped * (1 - theta_clamped)^3 / denom;
    else
        t = 0;                                    % 全面すべりでは接地圧分布が対称になりトレイルはゼロ
    end

    Mz = -t * Fy;                                 % 復元方向: alpha>0 のとき Mz>0
end
```

`Calpha_nominal`・`cp`・`a`・`mu`・`Fz0`・`Fz_table`/`Calpha_table`はいずれも実測値ではなく、学生フォーミュラ規模のタイヤでオーダーが合うように置いた仮の値です。自分のチームのタイヤで実際の値を使う場合は、この仮の値をそのまま使わず、第9章・第24章の手順で測定・同定した値に置き換えてください。

## 限界と適用範囲

`Fy = -C_α·α`という線形タイヤモデルは、次の6つの仮定の上に成り立っています。**この章の値打ちは、どこで最初に破綻するかを知っていることにあります。** 以下、破綻が早く効くもの（実務上の影響が大きいもの）から順に並べます。

**1. スリップ角が微小である。** 乾燥路のレーシングタイヤでは、おおよそ`|α| ≲ 2〜3 deg`（ピークスリップ角の1/3程度まで）が線形域の目安です（一般的な傾向としての目安であり、実測で確認すべき値です）。`|α|`がピークを越えると線形モデルは完全に破綻します。`Fy = -C_α·α`は`α`とともに`Fy`が無限に増え続けるので、限界旋回・スピン・カウンターステアは原理的に表現できません。この非線形域全体を表すのが第8章のMagic Formulaです。

**2. 接地荷重`F_z`が一定である。** この仮定を外した瞬間に破綻します。FSAEの車重・トレッド比では、定常旋回で片輪荷重が2倍近く振れることも珍しくなく、`C_α`一定で計算した横力の誤差は数%ではなく**十数%オーダー**になります（第13章参照。本章の荷重依存性の節で見た「約12%」の例もこの種の誤差です）。

**3. `Fx = 0`（前後力が働いていない）。** 加減速中の旋回（トレイルブレーキング、コーナー脱出の加速）では前後力`Fx`が入り、摩擦円（横力と前後力は同時に最大にできないという制約）が効くため、この章のモデルはまったく合いません。複合スリップは第10章で扱います。

**4. 定常（過渡遅れがない）。** 速いステア入力に対しては、緩和長による遅れでヨーレートの位相が合わなくなります（第2.6節で予告した過渡遅れ）。定義と実装は第7章、車両応答への影響は第5章です。

**5. 摩擦限界に達していない。** ニューマチックトレイル`t`は限界付近で急減し、ブラシモデルの解析解が示すとおりゼロに至ります（実際のタイヤではさらに符号が反転し負になることもあります）。一定トレールを仮定した`Mz = -C_α·α·t`（`t`一定、という追加の仮定）は、限界域での「ステアリングの手応え抜け」を再現できません。これは第20章（反力トルク）と第45章（DIL反力）が成立するための前提が崩れることを意味します。

**6. キャンバ角がゼロまたは無視できる。** 実際の`C_α`は接地荷重だけでなく、キャンバ角・内圧・温度によっても変化します。本章はこれらを無視しています。荷重・温度・キャンバの依存性を実務でどう扱うかは第11章でまとめて扱います。

**次の階層に進むべき条件。** 本章の`C_α(F_z)`によって第13章のロール剛性配分の**定性的な向き**（前寄りにするとアンダーステア方向に効く、という向き）が説明できるようになったら、そこから先の**定量精度**が必要になった段階で第8章（Magic Formula）へ進んでください。ただし`C_α(F_z)`の物理（なぜ劣線形になるのか）を飛ばしてMagic Formulaに進むと、荷重移動の物理を理解しないまま曲線フィットの係数を回すだけの作業になります。この章を経由する意味はそこにあります。

## 学生チームでの現実解

学生フォーミュラのチームが、自分たちの車両モデルに使う`C_α`を実際にどう入手するか、優先順位付きで示します。

1. **FSAE Tire Test Consortium（TTC）のデータを確認する。** FSAE界隈で広く使われているタイヤについては、TTCがタイヤ試験機での実測データをチーム単位の会員登録を通じて提供しています。自チームまたは他チームがTTCデータへのアクセスを持っている場合、それが最も信頼できる`C_α`の出発点になります。**登録が必要であることは確認できていますが、費用は本書執筆時点で確認できていないため、金額はここに書きません。** 公式ページで各自確認してください。TTCのデータは平面ベルト式の試験機（実路面とは`μ`の絶対値が異なる）で、FSAEの実走行速度に合わせた速度域（目安として時速25マイル前後）で取得されており、多くの場合SAE系の符号で配布されます。使うときは第1章の変換関数を通し、平面ベルト機と実路面の`μ`の差はスキッドパッド試験からの較正（第9章の`λμ`較正）で補正してください。
2. **TTCを持たないチームは、次の3つを優先順に検討する。**
   - **(a) 定常円旋回のアンダーステア勾配から前後`C_α`比を逆算する。** 一定半径の定常円旋回試験（第26章で扱う検証マニューバの1つ）を行い、そのときの横加速度・車速・舵角から、前後軸の実効的な`C_α`の**比**を逆算する方法です。比だけなら実車のみで取得でき、タイヤ単体の絶対値がなくても前後バランスの設計には使えます。ただしこの方法で得られるのはタイヤ単体ではなく「車両に組み付いた状態の軸全体」の値であり、サスペンションのコンプライアンスなど他の要因も混ざります。
   - **(b) 接地痕の実測から3パラメータのブラシモデルを閉じる。** 墨や粘土で接地痕を取って接地パッチ長`2a`を実測し、スキッドパッドでの最大横`G`から`μ`を決めれば、`C_α`の実測値（前段(a)で求まる、または簡易な定常円旋回試験でも近似できます）から`cp = C_α/(2a²)`を逆算できます。こうすると`cp`・`a`・`μ`の3パラメータが実測だけで閉じ、第2.4節のブラシモデルをそのまま自チームのタイヤの近似曲線として使えます。
   - **(c) Fialaタイプの解析解を既定値として車両モデルを先に完成させる。** 本章のブラシモデル（Fialaモデルと同じ構造の閉じた形です）に、オーダーが合う程度の仮のパラメータを入れて第3章以降のモデルを先に動かせる状態にしておき、実測が取れ次第、値だけを差し替えます。
3. **前後軸の`C_α`を、タイヤ1本の値の単純な定数倍にしない。** 前軸2輪・後軸2輪それぞれの荷重は、静止時の荷重配分に加えて、コーナリング中の横方向の荷重移動でも変化します。`C_α(F_z)`は劣線形なので、「1本の`C_α`を`K = 2·C_α`で単純に2倍する」だけでは、荷重移動が起きている軸のグリップを過大評価します。正しい積み上げ方は第13章で扱います。
4. **仮の値であることを必ず明記する。** どの経路で`C_α`を用意したかにかかわらず、値が仮測定・仮定であることをコードのコメントとチームのWikiに明記し、後から実測値に差し替える作業を忘れないようにします。
5. **今すぐ試せる最初のステップ：** 本章のMATLABコードをそのまま実行し、`cp`・`a`・`μ`を自チームのタイヤでオーダーが合う値に変えながら、原点の傾き（`2·cp·a²`）と摩擦飽和（`μ·Fz`）がどう動くかを手を動かして確認してください。さらに、`Fz_table`/`Calpha_table`の値を変えて、`Fz`を2倍にしたときの`C_α`の倍率が1.0〜2.0の間でどう変わるかも試してみてください。次章のバイシクルモデルに入る前に、`F_y`と`α`の逆符号・`C_α`の由来（ブラシモデル）・`C_α`の劣線形な荷重依存性という3つの感覚を持っておくと、モデルの結果が物理的に妥当かどうかを自分で判断できるようになります。

## 次の章へ

この章で固定した`F_y = -C_α·α`という関係と、`K = 2·C_α`という軸あたり・1輪あたりの変換規則を、次章（第3章「線形2自由度バイシクルモデル」）では前軸・後軸それぞれのタイヤに当てはめ、車両質量`m`・ヨー慣性`I_z`・重心位置（`l_f`・`l_r`）・前輪舵角`δ`と組み合わせて、車両全体の運動方程式を組み立てます。そこでは本章のように接地点の速度成分から直接`α`を求めるのではなく、車体すべり角`β`・ヨーレート`r`・車速`V`・舵角`δ`といった車両レベルの量から、前後軸の`α`を導出する形に一般化します。

第3章では`C_α`が定数（`F_z`一定の仮定つき）として扱われますが、この章で導いた`C_α(F_z)`の劣線形性は消えたわけではありません。第6章（このモデルの限界）でその仮定がいつ効いてくるかを地図にし、第13章（荷重移動とロール剛性配分）で本格的に組み込みます。
